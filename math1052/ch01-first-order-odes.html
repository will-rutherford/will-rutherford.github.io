§1 · Concepts in depth

Rusty on the single-variable toolkit — substitution, integration by parts, partial fractions, \(\int \tan x\,dx\), log laws? Read the Ground Floor — integrals (and exp & log) first. Every method in this chapter ends in "now integrate", and in a no-calculator exam that step is where marks are actually lost.

What an ODE is — the vocabulary markers expect

A differential equation (DE) is an equation involving an unknown function and its derivatives. If the unknown depends on one variable only (e.g. \(y(t)\) or \(y(x)\)) it is an ordinary DE (ODE); if it depends on several (e.g. \(u(x,t)\)) it is a partial DE (PDE). MATH1052 only solves ODEs.

  • Order = the highest derivative that appears. \(y' = y^2\) is first order; \(y''+2y'-y=1\) is second order; \(y^2\,\dfrac{d^3y}{dt^3}+\dfrac{dy}{dt}=t^2\) is third order (T01 Q1). Powers do not matter: \((y')^3=x\) is still first order.
  • Solution = a function which, when it and its derivatives are substituted in, makes the equation true identically (for every \(x\) in an interval).
  • General solution = the whole family of solutions, carrying an arbitrary constant (\(C\), \(A\), …). A first-order ODE has one arbitrary constant.
  • Initial value problem (IVP) = ODE + a condition \(y(t_0)=y_0\). The condition pins down the constant, so the answer has no arbitrary constants left.
  • Analytical solution = an exact formula; numerical solution = a table of approximate points (e.g. from Euler's method).
  • Dot notation: \(\dot y = dy/dt\), \(\ddot y=d^2y/dt^2\) (time derivatives). The 2020 S1 paper writes \(x\dot y\) — treat \(\dot y\) as "derivative of \(y\) with respect to the independent variable".

🧭 The big idea: an ODE is a rule for the slope

Write a first-order ODE as \(y' = f(t,y)\). Read it literally: "at the point \((t,y)\), the solution curve must have slope \(f(t,y)\)." The ODE does not tell you where the curve is — it tells you, at every point of the plane, which direction to move. A solution is any curve that obeys all those local instructions at once.

Three consequences drive the whole chapter:

  1. Slope fields are just this rule drawn as little line segments. Solution curves thread through them like iron filings following a magnet.
  2. Initial conditions matter: pick a starting point and the rule determines the rest of the curve. Different starting points → different members of the family (the constant \(C\)).
  3. Curves cannot cross (for the nice ODEs in this course): if two solutions met at a point, the same starting point would give two different futures. This uniqueness is exactly why equilibrium lines act as walls (Summary p 1: equilibria "cannot be crossed by other solution curves … partitioning the solution space").

Checking a solution — always possible, always worth marks

To show \(y=\phi(x)\) solves an ODE: differentiate \(\phi\), substitute into the left-hand side and right-hand side separately, and show they agree. Example (T01 Q2 pattern): for \(y=Ae^{-kt}\), \(y' = -kAe^{-kt}\) and \(-ky=-kAe^{-kt}\); equal for all \(t\), so it is a solution.

After solving any IVP, spend 30 seconds substituting back. It catches sign slips in the integrating factor, and in a "show that" question it is the answer.

🧭 Direct integration — the simplest case

If the right side depends only on the independent variable, \(\dfrac{dy}{dx}=f(x)\), then the ODE is literally "find an antiderivative": \(y=\int f(x)\,dx + C\). Newton's second law often lands here: acceleration \(a(t)\) given → integrate once for velocity, again for position, using the initial values each time (Summary p 1; see also Ch 7 projectiles).

🧭 Separable ODEs — why "splitting the \(dx\)" is legitimate

A first-order ODE is separable if the right side factors as (function of \(x\)) × (function of \(y\)):

$$\frac{dy}{dx}=f(x)\,g(y).$$

The trick "divide by \(g(y)\), multiply by \(dx\), integrate both sides" looks like cheating with differentials, but it is really the chain rule run backwards. If \(G(y)=\int \frac{1}{g(y)}dy\), then \(\frac{d}{dx}G(y(x)) = \frac{1}{g(y)}\frac{dy}{dx} = f(x)\). Integrate in \(x\): \(G(y)=\int f(x)\,dx + C\). That is the separated equation.

Recipe #1 (Summary p 2)
  1. Step 0 — equilibria first. Solve \(g(y)=0\). Each root \(y=a\) is a constant solution (a "singular solution") — record it before dividing by \(g(y)\), because dividing throws it away.
  2. For \(g(y)\neq0\): write \(\dfrac{1}{g(y)}\,dy = f(x)\,dx\).
  3. Integrate both sides; put one constant \(C\) on the \(x\)-side.
  4. Solve for \(y\) explicitly if you can; otherwise leave an implicit solution.
  5. Apply the initial condition; choose the correct branch (sign of a square root, etc.) using the initial condition.

\(e^{C}\) is a positive constant, but after removing absolute values \(|y-a| = e^{C}e^{F(x)}\) becomes \(y-a = Ae^{F(x)}\) with \(A\) any real number — including \(A=0\), which recovers the equilibrium you found in Step 0. Say this sentence; it shows the marker you know where the lost solution went.

🧭 Linear first-order ODEs — the integrating factor, from scratch

A first-order ODE is linear if \(y\) and \(y'\) appear only to the first power, not multiplied together, not inside functions:

$$\frac{dy}{dt}+p(t)\,y=q(t)\qquad\text{(standard form — coefficient of } y' \text{ must be } 1\text{)}.$$

Why the integrating factor works. The left side looks almost like a product-rule derivative. Multiply through by a function \(I(t)\): \(I y' + I p\,y = I q\). We want the left to equal \((I y)' = I y' + I' y\). That needs \(I' = I p\), i.e. \(I = e^{\int p\,dt}\). With that choice the ODE collapses to

$$\frac{d}{dt}\big(I\,y\big)=I\,q\quad\Longrightarrow\quad I\,y=\int I\,q\,dt + C\quad\Longrightarrow\quad y=\frac{1}{I}\Big(\int I q\,dt + C\Big).$$
Recipe #2 (Summary p 2)
  1. Rewrite in standard form \(y'+p(t)y=q(t)\) — divide by the coefficient of \(y'\) (state where it is nonzero).
  2. \(I=e^{\int p\,dt}\) — no constant needed here, and simplify \(e^{\ln|\cdot|}\).
  3. Write \(\dfrac{d}{dt}(Iy)=Iq\) — a marker looks for this line.
  4. Integrate with \(+C\), then divide by \(I\) (divide the \(C\) too!).

The most common fatal slip: dividing by \(I\) but forgetting to divide the constant. \(x^2y=x^4+C\) gives \(y=x^2+\dfrac{C}{x^2}\), not \(x^2+C\).

🧭 Substitution \(y=xu\): turning a stubborn ODE into a separable one

If the right side depends only on the ratio \(y/x\) — e.g. \(\dfrac{x+y}{x-y}=\dfrac{1+y/x}{1-y/x}\) — the ODE is called homogeneous. Put \(y=xu(x)\). Product rule: \(y' = u + x u'\). The ODE becomes \(u + x u' = F(u)\), i.e.

$$x\frac{du}{dx}=F(u)-u\quad\Longrightarrow\quad \frac{du}{F(u)-u}=\frac{dx}{x}\quad\text{— separable.}$$

This exact routine was a full 10-mark question (2020 S1 Q5). The official solution states the assumption \(x\ne0\), simplifies \(F(u)-u\) to a single fraction, and ends by writing the separated form \(\int \frac{1-u}{1+u^2}du=\int \frac1x dx\) with the word "separable!".

Slope fields — reading the picture

A slope field for \(y'=f(t,y)\) draws, at grid points \((a,b)\), a short segment of slope \(f(a,b)\). To match an ODE to a field (T01 Q4), hunt for distinguishing features, not individual slopes:

  • Horizontal lines of zero slope \(y=c\) ⇒ an equilibrium; check \(f(t,c)=0\) for all \(t\).
  • Isoclines: the curve where \(f=0\) (all segments flat) — e.g. \(y'=y^2+x^2-3\) is flat on the circle \(x^2+y^2=3\); \(y'=(x-y)^2-4\) is flat on the lines \(x-y=\pm2\).
  • Symmetry: if \(f(-x,y)=f(x,y)\) the field is mirror-symmetric in the \(y\)-axis; if \(f\) is unchanged by \(y\to-y\), symmetric in the \(x\)-axis.
  • Where slopes are steep/positive/negative: sign of \(f\) in each region.

🧭 Equilibrium solutions and stability — the phase-line picture

An equilibrium solution is a constant solution \(y(t)=c\). Since \(y'=0\) for a constant, you find them by solving \(f(t,c)=0\) for all \(t\). Graphically: a horizontal line in the slope field.

Stability asks what happens to solutions that start near the equilibrium, as \(t\) increases (Summary p 1):

TypeNearby solutions…Sign of \(y'\): just below / just above \(c\)Arrow picture
Stableapproach \(c\) from both sides\(+\) below, \(-\) above→ c ←

Semi-stable (counts as not stable)approach from one side, leave on the othersame sign on both sides→ c →  or  ← c ←

Why only the sign matters. If \(y'\gt0\) the solution is increasing; if \(y'\lt0\) it decreases. Since a solution can never cross an equilibrium line, a solution trapped between two equilibria must run monotonically toward one of them. So the sign of \(f\) between consecutive equilibria is all you need — no solving required.

Squared factors are the semi-stable giveaway. A factor \((y-c)^2\) does not change sign across \(c\), so \(y'\) has the same sign on both sides → semi-stable. Both 2020 papers used exactly this (\((y+4)^2\) in 2020 S2 Q1).

Non-autonomous ODEs. If \(f\) contains \(t\) (e.g. a factor \((t-2)\) or \(e^{t+y}\)), classify for large \(t\) ("as time increases"): fix the sign of every \(t\)-factor for \(t\) beyond some value (e.g. \(t\gt2\)), note positive factors like \(e^{t+y}\gt0\) and \((y+4)^2\ge0\), then do the sign table in \(y\). The official 2020 S2 Q1 solution does exactly this.

Poster B: "\(y'=0\) does not always yield an equilibrium solution. This could yield \(y=C\) at a particular time rather than for all \(t\)." E.g. \(y'=t+y\) is zero on the line \(y=-t\), which is not constant — so no equilibrium (T01 Q3b).

🧭 Euler's method — follow the tangent line, one small step at a time

When no formula is available, walk along the slope field. From \((t_n,y_n)\) take the tangent line (slope \(f(t_n,y_n)\)) for a horizontal distance \(\Delta t = h\):

$$t_{n+1}=t_n+h,\qquad y_{n+1}=y_n+h\,f(t_n,y_n).$$

This is just the linear approximation \(y(t+h)\approx y(t)+h\,y'(t)\) used repeatedly. Accuracy improves as \(h\to0\) (error roughly proportional to \(h\)).

  • Over or under? If the true solution is concave up (\(y''\gt0\)) the tangent lies below the curve ⇒ Euler underestimates. Concave down ⇒ overestimates. If the true solution is a straight line, Euler is exact.
  • Danger near equilibria (Poster B): a big step can jump over an equilibrium line — something the true solution can never do. Use a small \(h\).

Always lay out Euler as a table with columns \(n,\ t_n,\ y_n,\ f(t_n,y_n),\ y_{n+1}\). Keep exact fractions — no calculator in the exam, and fractions are easier to check.

§2 · Key methods & when to use them

None of this is on the formula sheet (the sheet covers only multivariable calculus). Every recipe below must be memorised — and the justification sentences are part of the method.

1 · Direct integration

$$\frac{dy}{dx}=f(x)\ \Longrightarrow\ y=\int f(x)\,dx+C$$
The right side has no \(y\) in it. Also: "given the acceleration, find velocity and position".

Mini-example. \(y'=3x^2+2,\ y(1)=4\): \(y=x^3+2x+C\); \(4=1+2+C\Rightarrow C=1\); \(\boxed{y=x^3+2x+1}\).

2 · Separable

$$\frac{dy}{dx}=f(x)g(y)\ \Longrightarrow\ \int\frac{dy}{g(y)}=\int f(x)\,dx + C\qquad(\text{plus equilibria } g(y)=0)$$
The right side factors into an \(x\)-part times a \(y\)-part. Hidden cases: \(e^{x-y}=e^x e^{-y}\); \(y'=1-t+y-ty=(1-t)(1+y)\); \(xy'+y=y^2 \Rightarrow y'=\frac{y^2-y}{x}\).

Mini-example. \(y'=2y,\ y(0)=3\): equilibrium \(y=0\); \(\int\frac{dy}{y}=\int2\,dx\Rightarrow \ln|y|=2x+C\Rightarrow y=Ae^{2x}\); \(A=3\): \(\boxed{y=3e^{2x}}\).

3 · Linear — integrating factor

$$y'+p(x)y=q(x),\qquad I=e^{\int p\,dx},\qquad (Iy)'=Iq,\qquad y=\frac1I\Big(\int Iq\,dx+C\Big)$$
\(y\) and \(y'\) appear linearly (no \(y^2\), \(\sin y\), \(yy'\)); the RHS does not factor, so separation fails.

Mini-example. \(y'+y=x\): \(I=e^x\); \((e^xy)'=xe^x\); by parts \(e^xy=(x-1)e^x+C\); \(\boxed{y=x-1+Ce^{-x}}\).

4 · Substitution \(y=xu\) (homogeneous ODEs)

$$y'=F\!\left(\tfrac yx\right),\quad y=xu,\quad y'=u+xu'\ \Longrightarrow\ \frac{du}{F(u)-u}=\frac{dx}{x}$$
Every term in numerator and denominator has the same total degree in \(x,y\) (e.g. \(\frac{x+y}{x-y}\), \(\frac{x^2+y^2}{xy}\)), or the question tells you to use \(y=xu\).

Mini-example. \(y'=\frac{x+y}{x}=1+u\): \(u+xu'=1+u\Rightarrow xu'=1\Rightarrow u=\ln|x|+C\Rightarrow y=x\ln|x|+Cx\).

5 · Equilibrium solutions & stability

  1. Rearrange to \(y'=f(t,y)\) (move all \(y'\) terms to one side and factor).
  2. Equilibria: constants \(c\) with \(f(t,c)=0\) for all \(t\). Check any excluded values (where you divided) directly in the original equation.
  3. Sign table of \(f\) between consecutive equilibria (fix the sign of \(t\)-factors for large \(t\)).
  4. Arrows up/down ⇒ stable / unstable / semi-stable. Conclude in words: "\(y=3\) is stable; \(y=-4\) is not stable (semi-stable)".
"Find all equilibrium solutions", "decide which are stable", "long-term behaviour", "what happens as \(t\to\infty\) if \(y(0)=\dots\)".

6 · Euler's method

$$t_{n+1}=t_n+h,\qquad y_{n+1}=y_n+h\,f(t_n,y_n)$$
"Approximate \(y(\cdot)\) using Euler's method with step size \(h\)", "numerical solution". Compare with the exact solution if one is given; use concavity to say over/under.

Mini-example. \(y'=ty,\ y(1)=2,\ h=0.1\): \(y_1=2+0.1\cdot(1)(2)=2.2\approx y(1.1)\).

7 · Standard models (know the solutions)

  • Cooling: \(T'=-k(T-T_m)\Rightarrow T=T_m+(T_0-T_m)e^{-kt}\). Two data points give \(k\); "halves every 10 min" ⇒ \(k=\frac{\ln2}{10}\).
  • Growth/decay: \(A'=\pm kA\Rightarrow A=A_0e^{\pm kt}\); half-life \(t_{1/2}=\frac{\ln 2}{k}\).
  • Logistic: \(P'=rP(1-P/\theta)\); equilibria \(0\) (unstable), \(\theta\) (stable); fastest growth at \(P=\theta/2\).
  • Mixing: \(S'=c_{\text{in}}r_{\text{in}}-r_{\text{out}}\dfrac{S}{V(t)}\), \(V(t)=V_0+(r_{\text{in}}-r_{\text{out}})t\).
  • Linear drag: \(v'=g-\frac kmv\); terminal velocity = the stable equilibrium \(v=\frac{mg}{k}\).
Word problems: "rate proportional to…", "well-stirred tank", "surrounding temperature", "carrying capacity", "air resistance proportional to velocity".

Example 1 — Separable IVP with an equilibrium: \(y'=3x^2(y-2),\ y(0)=5\)

Q. Solve the IVP \(\dfrac{dy}{dx}=3x^2(y-2)\), \(y(0)=5\). [6 marks]

RHS = \(3x^2\) (only \(x\)) × \((y-2)\) (only \(y\)) ⇒ separable.

Equilibria. \(y-2=0\Rightarrow y=2\) is a constant solution. It does not satisfy \(y(0)=5\), so for our IVP \(y\ne2\) and we may divide.

$$\int\frac{dy}{y-2}=\int3x^2\,dx\ \Longrightarrow\ \ln|y-2|=x^3+C\ \Longrightarrow\ y-2=Ae^{x^3}\quad(A=\pm e^{C};\ A=0\text{ gives the equilibrium}).$$

IC. \(5-2=Ae^0\Rightarrow A=3\).

$$\boxed{y=2+3e^{x^3}}$$

Check. \(y'=9x^2e^{x^3}\) and \(3x^2(y-2)=3x^2\cdot3e^{x^3}=9x^2e^{x^3}\). ✓

Example 2 — Choosing the square-root branch: \(y'=\dfrac{x+1}{y},\ y(0)=-3\)

Q. Solve \(\dfrac{dy}{dx}=\dfrac{x+1}{y}\), \(y(0)=-3\), giving \(y\) explicitly and stating where the solution is valid. [6 marks]

\(\frac{x+1}{y}=(x+1)\cdot\frac1y\) ⇒ separable. No equilibria (\(1/y\) is never 0).
$$\int y\,dy=\int(x+1)\,dx\ \Longrightarrow\ \tfrac12y^2=\tfrac12x^2+x+C\ \Longrightarrow\ y^2=x^2+2x+K.$$

IC. \(9=0+0+K\Rightarrow K=9\), so \(y^2=x^2+2x+9\). Two branches \(y=\pm\sqrt{x^2+2x+9}\); the IC has \(y(0)=-3\lt0\), so take the negative root:

$$\boxed{y=-\sqrt{x^2+2x+9}}$$

Domain. \(x^2+2x+9=(x+1)^2+8\ge8\gt0\) for all \(x\), so the solution is valid on all of \(\mathbb R\) (and never reaches \(y=0\), where the ODE is undefined).

Marker's line: "since \(y(0)=-3\lt0\) we take the negative square root". The positive root is a solution of the ODE but not of the IVP.

Example 3 — Linear with variable coefficient: \(xy'+2y=4x^2,\ y(1)=3\)

Q. Solve \(xy'+2y=4x^2\) for \(x\gt0\) with \(y(1)=3\). [7 marks]

\(y\) and \(y'\) appear linearly; RHS does not factor as \(f(x)g(y)\) ⇒ integrating factor.

Standard form (divide by \(x\ne0\)): \(y'+\dfrac2x\,y=4x\).

IF. \(I=e^{\int 2/x\,dx}=e^{2\ln x}=x^2\) (using \(x\gt0\)).

$$\frac{d}{dx}\big(x^2y\big)=x^2\cdot4x=4x^3\ \Longrightarrow\ x^2y=x^4+C\ \Longrightarrow\ y=x^2+\frac{C}{x^2}.$$

IC. \(3=1+C\Rightarrow C=2\).

$$\boxed{y=x^2+\frac{2}{x^2},\quad x\gt0}$$

Check. \(y'=2x-4x^{-3}\); \(xy'+2y=2x^2-4x^{-2}+2x^2+4x^{-2}=4x^2\). ✓

Example 4 — Linear with exponential forcing: \(y'+2y=6e^{t},\ y(0)=5\)

Q. Solve the IVP. What does \(y\) look like for large \(t\)? [6 marks]

IF. \(I=e^{\int2\,dt}=e^{2t}\).

$$\big(e^{2t}y\big)'=6e^{3t}\ \Longrightarrow\ e^{2t}y=2e^{3t}+C\ \Longrightarrow\ y=2e^{t}+Ce^{-2t}.$$

IC. \(5=2+C\Rightarrow C=3\): \(\boxed{y=2e^{t}+3e^{-2t}}\).

Large \(t\). \(3e^{-2t}\to0\), so \(y\approx2e^t\): the "transient" dies out and the solution follows the forcing.

Example 5 — Trig coefficient (2020 S2 Q2 style): \(y'+y\tan x=\cos^2x\) on \(\left(-\frac\pi2,\frac\pi2\right)\)

Q. Find the general solution on \(-\frac\pi2\lt x\lt\frac\pi2\), then the solution with \(y(0)=2\). [8 marks]

Domain remark (worth a mark in 2020 S2 Q2's scheme): on \(\left(-\frac\pi2,\frac\pi2\right)\), \(\cos x\gt0\), so \(|\cos x|=\cos x\).

IF. \(\int\tan x\,dx=-\ln|\cos x|\), so \(I=e^{-\ln\cos x}=\dfrac1{\cos x}=\sec x\).

$$\frac{d}{dx}\big(y\sec x\big)=\cos^2x\cdot\sec x=\cos x\ \Longrightarrow\ y\sec x=\sin x+C\ \Longrightarrow\ \boxed{y=\sin x\cos x+C\cos x}.$$

IC. \(y(0)=0+C=2\Rightarrow \boxed{y=\sin x\cos x+2\cos x}\).

Example 6 — Equilibria & stability with a squared factor: \(y'=y(y-2)(y+3)^2\)

Q. Find all equilibrium solutions and classify each as stable, unstable or semi-stable. Describe the long-term behaviour of the solution with \(y(0)=1\). [8 marks]

Equilibria. \(y'=0\iff y=0,\ y=2,\ y=-3\) — constant, so all three are equilibrium solutions.

Region\(y\)\(y-2\)\((y+3)^2\)\(y'\)Motion
\(y\gt2\)++++up ↑
\(0\lt y\lt2\)+−+−down ↓
\(-3\lt y\lt0\)−−++up ↑

  • \(y=2\): below moves down, above moves up ⇒ unstable.
  • \(y=0\): below (\(-3\lt y\lt0\)) moves up to it, above (\(0\lt y\lt2\)) moves down to it ⇒ stable.
  • \(y=-3\): below moves up toward it, above moves up away ⇒ semi-stable (not stable). The squared factor is the reason.

\(y(0)=1\). Starts in \(0\lt y\lt2\) where \(y'\lt0\); it cannot cross \(y=0\), so it decreases and \(y(t)\to0\) as \(t\to\infty\).

(b) \(y'=2-3e^{-x}\) and \(2x-y=2x-2x+2-3e^{-x}=2-3e^{-x}\) ✓; \(y(0)=-2+3=1\) ✓. Exact \(y(1.5)=1+3e^{-1.5}\approx1.669\). Since \(y''=3e^{-x}\gt0\) the solution is concave up, tangent lines lie below it, so Euler underestimates — consistent with \(1.375\lt1.669\).

Example 8 — Newton's law of cooling (clean logs)

Q. A cup of coffee at \(90^\circ\)C is left in a \(20^\circ\)C room. After 10 minutes it is \(55^\circ\)C. Assuming Newton's law of cooling, (a) find \(T(t)\); (b) find when it reaches \(37.5^\circ\)C. [7 marks]

Model. \(\dfrac{dT}{dt}=-k(T-20)\), \(k\gt0\) ⇒ \(T=20+(90-20)e^{-kt}=20+70e^{-kt}\).

Find \(k\). \(55=20+70e^{-10k}\Rightarrow e^{-10k}=\tfrac12\Rightarrow k=\dfrac{\ln2}{10}\) per minute. So \(\boxed{T=20+70\cdot2^{-t/10}}\).

(b) \(37.5=20+70e^{-kt}\Rightarrow e^{-kt}=\tfrac14=\left(\tfrac12\right)^2\Rightarrow t=\boxed{20\text{ min}}\).

Excess temperature \(T-T_m\) halves every 10 minutes: 70 → 35 → 17.5. Spotting the halving pattern avoids any logs.

Example 9 — Mixing tank (constant volume)

Q. A 100 L tank holds brine containing 10 kg of salt. Brine with concentration 0.2 kg/L flows in at 5 L/min; the well-stirred mixture flows out at 5 L/min. Find the salt \(S(t)\) and the time at which the tank holds 15 kg. [8 marks]

Rates. In: \(0.2\times5=1\) kg/min. Out: \(5\times\dfrac{S}{100}=\dfrac{S}{20}\) kg/min (volume stays 100 L).

$$\frac{dS}{dt}=1-\frac{S}{20},\qquad S(0)=10.$$

Linear: \(I=e^{t/20}\); \((e^{t/20}S)'=e^{t/20}\Rightarrow e^{t/20}S=20e^{t/20}+C\Rightarrow S=20+Ce^{-t/20}\); \(C=-10\):

$$\boxed{S(t)=20-10e^{-t/20}}\qquad S=15\iff e^{-t/20}=\tfrac12\iff t=\boxed{20\ln2\ \text{min}}.$$

Sense check. Equilibrium \(S=20\) kg \(=0.2\times100\): eventually the tank has the inflow concentration. It is stable.

Example 10 — Substitution \(y=xu\): \(y'=\dfrac{x^2+y^2}{xy},\ y(1)=2\)

Q. Use \(y=xu(x)\) to show the ODE becomes separable, then solve the IVP for \(x\gt0\). [10 marks]

Assume \(x\ne0\). With \(y=xu\): \(y'=u+xu'\) and \(\dfrac{x^2+x^2u^2}{x\cdot xu}=\dfrac{1+u^2}{u}=u+\dfrac1u\).

$$u+x\frac{du}{dx}=u+\frac1u\ \Longrightarrow\ x\frac{du}{dx}=\frac1u\ \Longrightarrow\ \frac{du}{dx}=\frac1x\cdot\frac1u\quad\text{— separable.}$$ $$\int u\,du=\int\frac{dx}{x}\ \Longrightarrow\ \tfrac12u^2=\ln x+C.$$

IC: \(u(1)=y(1)/1=2\Rightarrow 2=0+C\Rightarrow C=2\). So \(u^2=2\ln x+4\), \(u\gt0\) (since \(u(1)=2\gt0\)):

$$\boxed{y=x\sqrt{2\ln x+4}},\qquad\text{valid for } x\gt e^{-2}.$$

Type A — Equilibrium solutions & stability 2020 S2 Q1 [10] · 2020 S1 Q10 [10]

Looks like: "Find all equilibrium solutions of the following ODE … Decide which of these equilibrium solutions are stable. Justify your answer." Sometimes the ODE is given unrearranged (2020 S1 Q10) so you must collect the \(\dot y\) terms first.

Recipe:
  1. (Rearrange to \(y'=f(t,y)\) and factor.)
  2. Set \(y'=0\); keep only constant roots. Check excluded values in the original equation.
  3. Sign of every factor: exponentials always \(\gt0\); squares \(\ge0\); \((t-2)\gt0\) for \(t\gt2\).
  4. Sign of \(y'\) in each \(y\)-region ⇒ arrows ⇒ stable / not stable (semi-stable) / unstable.

📄 Real exam question — 2020 S2 Q1 [10 marks]

Find all equilibrium solutions of the following ODE:

$$\frac{dy}{dt}=e^{t+y}(3-y)(y+4)^2(t-2).$$

Decide which of these equilibrium solutions are stable. Justify your answer.

Full worked solution — 2020 S2 Q1 (with the official mark allocation)

Equilibria [2 marks]. \(\dot y=0\) for all \(t\) requires \((3-y)(y+4)^2=0\) (since \(e^{t+y}\ne0\), and \(t-2\) is not zero for all \(t\)): \(\boxed{y=3,\ y=-4}\).

Signs of the factors [3 marks]. For \(t\gt2\): \(t-2\gt0\); \(e^{t+y}\gt0\) for all \(t,y\); \((y+4)^2\gt0\) for \(y\ne-4\); \(3-y\gt0\iff y\lt3\).

Sign of \(\dot y\) for \(t\gt2\) [3 marks].

  • \(y\gt3\): \(\dot y\lt0\) (moves down toward 3)
  • \(-4\lt y\lt3\): \(\dot y\gt0\) (moves up toward 3, away from \(-4\))
  • \(y\lt-4\): \(\dot y\gt0\) (moves up toward \(-4\))

Conclusion [1 + 1 marks]. \(\boxed{y=3\text{ is stable}}\); \(\boxed{y=-4\text{ is not stable (semi-stable)}}\).

The official solution draws a \(t\)–\(y\) sketch with the two red horizontal lines, green curves approaching 3, and arrows at \(-4\) pointing the same way on both sides. A quick sketch like that is accepted as "equivalent working" for the sign marks.

📄 Real exam question — 2020 S1 Q10 [10 marks]

(i) (5 marks) Determine all equilibrium solutions to the ODE

$$x\dot y+x-y=y^2x\dot y+xy-1.$$

(ii) (5 marks) Determine if each equilibrium solution is stable or not. Justify your answer.

Full worked solution — 2020 S1 Q10

(i) \(y=c\) is an equilibrium iff it satisfies the ODE with \(\dot y=0\) for all \(x\):

$$0+x-c=0+xc-1\iff xc+c-1-x=0\iff (c-1)(x+1)=0\ \text{for all }x\iff c=1.$$

So \(\boxed{y=1}\) is the only equilibrium solution. (Note \(y=-1\) is not one: it gives \(x+1=-x-1\), true only at \(x=-1\).)

(ii) Collect the \(\dot y\) terms: \(\dot y\,(x-y^2x)=xy-1-x+y\), i.e.

$$\dot y=\frac{(x+1)(y-1)}{x(1-y^2)},\qquad x\ne0,\ y\ne\pm1.$$

For large \(x\) (\(x\gt0\), so \(x+1\gt0\)):

  • \(y\gt1\): numerator \(+\cdot+\), denominator \(+\cdot-\) ⇒ \(\dot y\lt0\) (moves down toward 1).
  • \(-1\lt y\lt1\): numerator \(+\cdot-\), denominator \(+\cdot+\) ⇒ \(\dot y\lt0\) (moves down away from 1).

Same sign on both sides ⇒ \(\boxed{y=1\text{ is semi-stable, i.e. not stable}}\) (official answer: "semi-stable").

Cancelling \((y-1)\) gives \(\dot y=-\frac{x+1}{x(1+y)}\), which is non-zero at \(y=1\) — so if you cancel first you "lose" the equilibrium. Find equilibria from the original equation, exactly as the official solution does.

Type B — Linear first-order ODE via integrating factor 2020 S2 Q2 [10]

Looks like: "Find the general solution of the following ODE, assuming \(0\lt x\lt\frac\pi2\)" with trig coefficients in front of \(y'\) and \(y\). The interval is a hint: it fixes the signs of \(\sin x,\cos x\) so the absolute values in \(e^{\ln|\cdot|}\) can be dropped.

Recipe: divide by the coefficient of \(y'\) → \(I=e^{\int p}\) → \((Iy)'=Iq\) → integrate with \(+C\) → divide by \(I\).

📄 Real exam question — 2020 S2 Q2 [10 marks]

Find the general solution of the following ODE, assuming \(0\lt x\lt\frac\pi2\):

$$\sin(x)\cos^2(x)\,y'+\cos^3(x)\,y=1.$$
Full worked solution — 2020 S2 Q2 (with the official mark allocation)

[1 mark] For \(x\in(0,\frac\pi2)\): \(\sin x\gt0,\ \cos x\gt0\) (so we may divide by them).

Standard form: divide by \(\sin x\cos^2x\):

$$y'+\frac{\cos x}{\sin x}\,y=\frac{1}{\sin x\cos^2x}.$$

IF [3 marks]: \(I=e^{\int\cot x\,dx}=e^{\ln|\sin x|}=|\sin x|=\sin x\) on \((0,\frac\pi2)\).

[2 marks] \(\dfrac{d}{dx}\big(y\sin x\big)=\dfrac{\sin x}{\sin x\cos^2x}=\dfrac1{\cos^2x}\).

[2 marks] \(y\sin x=\displaystyle\int\sec^2x\,dx=\tan x+C\).

[2 marks] General solution:

$$\boxed{y=\frac{1}{\cos x}+\frac{C}{\sin x}=\sec x+C\csc x,\quad C\in\mathbb R.}$$

Either form earns the final 2 marks. Writing "\(C\in\mathbb R\)" shows you know it is a family.

Type C — Substitution that makes an ODE separable 2020 S1 Q5 [10]

Looks like: "show that it becomes separable using the substitution \(y(x)=xu(x)\). (You do not need to solve the ODE.)" — the marks are for the substitution algebra, ending in the form \(u'=f(x)g(u)\).

📄 Real exam question — 2020 S1 Q5 [10 marks]

Consider the ODE

$$\frac{dy}{dx}=\frac{x+y}{x-y},$$

and show that it becomes separable using the substitution \(y(x)=xu(x)\). (You do not need to solve the ODE.)

Full worked solution — 2020 S1 Q5

Let \(y=xu(x)\). By the product rule \(\dfrac{dy}{dx}=u+x\dfrac{du}{dx}\). Substitute, assuming \(x\ne0\):

$$u+x\frac{du}{dx}=\frac{x+xu}{x-xu}=\frac{x(1+u)}{x(1-u)}=\frac{1+u}{1-u}.$$ $$x\frac{du}{dx}=\frac{1+u}{1-u}-u=\frac{1+u-u(1-u)}{1-u}=\frac{1+u^2}{1-u}.$$ $$\frac{du}{dx}=\left(\frac1x\right)\left(\frac{1+u^2}{1-u}\right)=f(x)\,g(u)\quad\text{— separable, with } f(x)=\tfrac1x,\ g(u)=\tfrac{1+u^2}{1-u}.$$

Equivalently \(\displaystyle\int\frac{1-u}{1+u^2}\,du=\int\frac1x\,dx\) (\(u\ne1\)).

Not required, but for completeness: \(\arctan u-\tfrac12\ln(1+u^2)=\ln|x|+C\), with \(u=y/x\).

§6 · Traps & marks lost

Losing equilibria by dividing. Dividing by \(g(y)\) (separable) or cancelling a factor like \((y-1)\) (2020 S1 Q10) silently removes constant solutions. Find equilibria before dividing and state them.
Semi-stable is "not stable". The 2020 S2 marking scheme awards the mark for "−4 not stable (semi-stable)". Never call a one-sided equilibrium "stable". The trigger is a squared factor \((y-c)^2\).
"\(y'=0\) at a point" is not an equilibrium. An equilibrium is a constant function. \(y'=t+y\) has no equilibria even though \(y'=0\) along \(y=-t\) (T01 Q3b; Poster B).
Integrating factor from the wrong form. \(I=e^{\int p}\) only when the coefficient of \(y'\) is 1. In 2020 S2 Q2 you must first divide by \(\sin x\cos^2x\); using \(\cos^3x\) as "\(p\)" is worth zero.
Forgetting to divide \(C\) by \(I\). \(y\sin x=\tan x+C\Rightarrow y=\sec x+C\csc x\), not \(\sec x+C\).
Dropping absolute values without justification. \(e^{\ln|\sin x|}=|\sin x|\). You may write \(\sin x\) only because the question restricts \(0\lt x\lt\frac\pi2\) — and the scheme gives a mark for saying so.
Constant placed in the wrong spot. \(\ln|y|=x^2+C\Rightarrow y=Ae^{x^2}\), not \(e^{x^2}+C\). Exponentiate the whole side, and the constant becomes a multiplier.
Wrong square-root branch. From \(y^2=\dots\) choose the sign that matches the initial condition, and say why.
Substitution derivative. With \(y=xu\), \(y'=u+xu'\) — not \(u'\) and not \(xu'\). Product rule.
Euler uses the slope at the left end. \(y_{n+1}=y_n+hf(t_n,y_n)\): evaluate \(f\) at the point you are at, not the point you are going to. And update \(t\) as well as \(y\).
Cooling constant sign. Write \(T'=-k(T-T_m)\) with \(k\gt0\). If you write \(+k\) you must get \(k\lt0\), and answers about "\(k\)" become confusing.
Non-autonomous stability without fixing \(t\). With a factor like \((t-2)\), the sign of \(y'\) flips at \(t=2\). State "for \(t\gt2\)" before the sign table — stability is about \(t\to\infty\).

§7 · Self-check

1. What is the order of \(\left(\dfrac{dy}{dx}\right)^3+y\dfrac{d^2y}{dx^2}=\sin x\)? Is it linear?

Second order (highest derivative \(y''\)). Nonlinear — \((y')^3\) and the product \(yy''\).

2. Solve \(y'=5y,\ y(0)=7\) in one line.

\(y=7e^{5x}\) (separable / exponential growth).

3. Is \(y'=e^{x+y}\) separable? Linear?

Separable: \(e^{x+y}=e^x\cdot e^y\). Not linear (\(e^y\)).

4. The integrating factor for \(y'-\dfrac2x\,y=x\) (\(x\gt0\))?

\(I=e^{\int-2/x\,dx}=e^{-2\ln x}=x^{-2}\).

5. Why do we not need a constant of integration inside the integrating factor?

Any constant \(K\) gives \(I=e^{K}e^{\int p}\), a constant multiple; it cancels when you divide by \(I\) at the end (Summary p 2: "ignoring any constants of integration").

6. Classify the equilibria of \(y'=y^2-1\).

\(y=\pm1\). For \(y\gt1\): \(+\); \(-1\lt y\lt1\): \(-\); \(y\lt-1\): \(+\). So \(y=1\) unstable, \(y=-1\) stable.

7. Classify \(y=0\) for \(y'=y^2\).

\(y'\gt0\) on both sides ⇒ semi-stable (not stable).

8. Does \(y'=t-y\) have an equilibrium solution?

No: \(y'=0\) needs \(y=t\), which is not constant.

9. One Euler step: \(y'=x+y,\ y(0)=2,\ h=0.25\). Estimate \(y(0.25)\).

\(y_1=2+0.25(0+2)=2.5\).

10. A solution is concave down. Does Euler over- or under-estimate?

Overestimates — tangent lines lie above a concave-down curve.

11. Can two different solutions of \(y'=y(3-y)\) cross? Why does this matter for stability?

No — uniqueness. So a solution starting between 0 and 3 is trapped between those equilibria and must head monotonically to one of them (here to 3, since \(y'\gt0\) there).

12. Cooling: the excess temperature halves every 8 min. What is \(k\)?

\(e^{-8k}=\tfrac12\Rightarrow k=\dfrac{\ln2}{8}\) per min.

13. With \(y=xu\), what does \(y'=\dfrac{y}{x}+\dfrac{x}{y}\) become?

\(u+xu'=u+\frac1u\Rightarrow xu'=\frac1u\) — separable: \(u\,du=\frac{dx}{x}\).

14. Logistic \(P'=0.3P(1-P/800)\): where is growth fastest? Which equilibrium is stable?

Fastest at \(P=400\) (\(=\theta/2\)). \(P=800\) stable, \(P=0\) unstable.

15. A tank's volume is 50 L, inflow 3 L/min, outflow 5 L/min. What is \(V(t)\) and when is the model valid?

\(V=50-2t\), valid for \(0\le t\lt25\) (tank empties at \(t=25\)).

Worked A — verify a family, then fit an initial condition

Q. (a) Show that \(y=(x+C)e^{-x}\) is a solution of \(y'+y=e^{-x}\) for every constant \(C\). (b) Find the solution with \(y(0)=4\). (c) State the order of the ODE and whether it is linear. [5 marks]

(a) Product rule: \(y'=e^{-x}-(x+C)e^{-x}\). Then

$$y'+y=e^{-x}-(x+C)e^{-x}+(x+C)e^{-x}=e^{-x}=\text{RHS}.\ ✓$$

(b) \(y(0)=C=4\Rightarrow \boxed{y=(x+4)e^{-x}}\).

(c) First order (highest derivative \(y'\)); linear (\(y,y'\) to the first power, coefficients depend only on \(x\)).

Worked B — direct integration with a log

Q. Solve \(\dfrac{dy}{dx}=\dfrac{x}{x^2+1}\), \(y(0)=3\). [3 marks]

Substitute \(w=x^2+1\), \(dw=2x\,dx\): \(\displaystyle y=\int\frac{x}{x^2+1}dx=\tfrac12\ln(x^2+1)+C\) (no absolute value needed: \(x^2+1\gt0\)).

\(y(0)=0+C=3\Rightarrow \boxed{y=\tfrac12\ln(x^2+1)+3}\).

WARM-UP · 4 marks Q1. State the order of each ODE and whether it is linear or nonlinear: (a) \(y'''+yy'=x\); (b) \((y')^2+y=0\); (c) \(t^2\ddot y-y=e^t\); (d) \(\dfrac{dy}{dx}=\sin(xy)\).

Solution

(a) Third order, nonlinear (product \(yy'\)). (b) First order, nonlinear (\((y')^2\)). (c) Second order, linear (coefficients \(t^2\), \(-1\) depend on \(t\) only). (d) First order, nonlinear (\(y\) inside \(\sin\)).

STANDARD · 5 marks Q2. (a) Show that \(y=\dfrac{2}{1+Ce^{-2x}}\) solves \(y'=y(2-y)\) for every constant \(C\). (b) Find \(C\) so that \(y(0)=1\). (c) Which constant solution of the ODE is not of this form?

Solution

(a) \(y=2(1+Ce^{-2x})^{-1}\Rightarrow y'=\dfrac{4Ce^{-2x}}{(1+Ce^{-2x})^2}\). Also \(2-y=\dfrac{2Ce^{-2x}}{1+Ce^{-2x}}\), so \(y(2-y)=\dfrac{2}{1+Ce^{-2x}}\cdot\dfrac{2Ce^{-2x}}{1+Ce^{-2x}}=\dfrac{4Ce^{-2x}}{(1+Ce^{-2x})^2}=y'\). ✓

(b) \(1=\dfrac{2}{1+C}\Rightarrow C=1\): \(y=\dfrac{2}{1+e^{-2x}}\).

(c) The equilibria are \(y=0\) and \(y=2\). \(C=0\) gives \(y=2\), but no \(C\) gives \(y=0\), so \(y=0\) is the missing solution.

EXAM-LEVEL · 6 marks Q3. A particle moves on a line with acceleration \(a(t)=6t-12\) m/s². Its initial velocity is \(9\) m/s and initial position is \(0\) m. (a) Find \(v(t)\) and \(s(t)\). (b) When is the particle at rest? (c) Where is it at \(t=1\) and \(t=3\)?

Solution

(a) \(v=\int(6t-12)\,dt=3t^2-12t+C_1\); \(v(0)=9\Rightarrow C_1=9\): \(v=3t^2-12t+9=3(t-1)(t-3)\). Then \(s=t^3-6t^2+9t+C_2\); \(s(0)=0\Rightarrow C_2=0\): \(\boxed{s=t^3-6t^2+9t}\).

(b) \(v=0\iff t=1\) or \(t=3\) s.

(c) \(s(1)=1-6+9=4\) m; \(s(3)=27-54+27=0\) m — back at the start.

EXAM-LEVEL · 4 marks Q4. Find constants \(a,b\) such that \(y=ax+b\) is a solution of \(y'=2y-4x+1\). Is this an equilibrium solution? Explain.

Solution

\(y'=a\) and \(2(ax+b)-4x+1=(2a-4)x+(2b+1)\). Equate for all \(x\): \(2a-4=0\Rightarrow a=2\); \(2b+1=a=2\Rightarrow b=\tfrac12\). So \(\boxed{y=2x+\tfrac12}\).

Not an equilibrium: an equilibrium solution must be constant, and this one has slope 2.

STRETCH · 5 marks Q5. (a) Show that \(y=Cx^2\) solves \(xy'=2y\) for every \(C\). (b) Explain why the IVP \(xy'=2y,\ y(0)=0\) has infinitely many solutions while \(xy'=2y,\ y(0)=1\) has none. (c) Why does this not contradict "solution curves never cross"?

Solution

(a) \(y'=2Cx\Rightarrow xy'=2Cx^2=2y\). ✓

(b) Every parabola \(y=Cx^2\) passes through \((0,0)\), so \(y(0)=0\) is satisfied for every \(C\) ⇒ infinitely many. At \(x=0\) the ODE reads \(0=2y(0)\), forcing \(y(0)=0\), so \(y(0)=1\) is impossible.

(c) In standard form \(y'=2y/x\) the right side is undefined at \(x=0\); uniqueness (and "no crossing") is only guaranteed where \(f(x,y)\) is well-behaved. All the crossings happen on the bad line \(x=0\).

8.2 · Separable ODEs (and the \(y=xu\) substitution)

📖 Learn from these

Worked A — blow-up and the interval of validity: \(y'=xy^2,\ y(0)=\tfrac12\)

Q. Solve the IVP and state the largest interval containing \(x=0\) on which the solution exists. [6 marks]

Equilibrium: \(y=0\) (not our IVP, since \(y(0)=\tfrac12\)).

$$\int y^{-2}\,dy=\int x\,dx\ \Longrightarrow\ -\frac1y=\frac{x^2}{2}+C.$$

IC: \(-2=0+C\Rightarrow C=-2\). So \(\dfrac1y=2-\dfrac{x^2}{2}=\dfrac{4-x^2}{2}\):

$$\boxed{y=\frac{2}{4-x^2},\qquad -2\lt x\lt2.}$$

The denominator vanishes at \(x=\pm2\) — the solution blows up there, so the interval containing \(0\) is \((-2,2)\).

Worked B — hidden separability: \(y'=e^{x-y},\ y(0)=\ln2\)

Q. Solve the IVP. [5 marks]

\(e^{x-y}=e^x\cdot e^{-y}\) ⇒ separable; no equilibria (\(e^{-y}\gt0\)).

$$\int e^{y}\,dy=\int e^{x}\,dx\ \Longrightarrow\ e^y=e^x+C.$$

IC: \(e^{\ln2}=2=1+C\Rightarrow C=1\). So \(e^y=e^x+1\) and \(\boxed{y=\ln(e^x+1)}\), valid for all \(x\) since \(e^x+1\gt0\).

WARM-UP · 3 marks Q1. Solve \(\dfrac{dy}{dt}=-3t^2y\), \(y(0)=4\).

Solution

Equilibrium \(y=0\). \(\int\frac{dy}{y}=\int-3t^2\,dt\Rightarrow\ln|y|=-t^3+C\Rightarrow y=Ae^{-t^3}\). \(A=4\): \(\boxed{y=4e^{-t^3}}\).

STANDARD · 5 marks Q2. Solve \(\dfrac{dy}{dx}=(y+1)\sec^2x\), \(y(0)=1\), on \(-\frac\pi2\lt x\lt\frac\pi2\). Identify any equilibrium solution.

Solution

Equilibrium: \(y=-1\). Otherwise \(\int\frac{dy}{y+1}=\int\sec^2x\,dx\Rightarrow\ln|y+1|=\tan x+C\Rightarrow y+1=Ae^{\tan x}\).

IC: \(2=Ae^0\Rightarrow A=2\): \(\boxed{y=2e^{\tan x}-1}\).

EXAM-LEVEL · 7 marks Q3. Solve \(\dfrac{dy}{dx}=\dfrac{x(1+y^2)}{y}\), \(y(0)=-\sqrt3\), giving \(y\) explicitly.

Solution

Separable; \(1+y^2\ne0\), so no equilibria.

$$\int\frac{y}{1+y^2}dy=\int x\,dx\ \Longrightarrow\ \tfrac12\ln(1+y^2)=\tfrac12x^2+C\ \Longrightarrow\ 1+y^2=Ae^{x^2}.$$

IC: \(1+3=A\Rightarrow A=4\). So \(y^2=4e^{x^2}-1\); since \(y(0)=-\sqrt3\lt0\) take the negative root:

$$\boxed{y=-\sqrt{4e^{x^2}-1}}\quad(\text{valid for all }x,\ \text{as }4e^{x^2}-1\ge3).$$

EXAM-LEVEL · 8 marks Q4. Consider \(\dfrac{dy}{dt}=4-y^2\). (a) Find the equilibrium solutions and classify them. (b) Solve the IVP with \(y(0)=0\) using partial fractions. (c) Find \(\lim_{t\to\infty}y(t)\) and check it agrees with (a).

Solution

(a) \(4-y^2=(2-y)(2+y)=0\Rightarrow y=\pm2\). Signs: \(y\gt2\): \(-\); \(-2\lt y\lt2\): \(+\); \(y\lt-2\): \(-\). So \(y=2\) stable, \(y=-2\) unstable.

(b) \(\dfrac{1}{4-y^2}=\dfrac14\left(\dfrac{1}{2+y}+\dfrac{1}{2-y}\right)\), so

$$\tfrac14\ln\left|\frac{2+y}{2-y}\right|=t+C\ \Longrightarrow\ \frac{2+y}{2-y}=Ae^{4t}.$$

IC \(y(0)=0\Rightarrow A=1\). Solve: \(2+y=(2-y)e^{4t}\Rightarrow y(1+e^{4t})=2(e^{4t}-1)\):

$$\boxed{y=\frac{2(e^{4t}-1)}{e^{4t}+1}}.$$

(c) Divide top and bottom by \(e^{4t}\): \(y\to2\). ✓ The solution starts between the equilibria where \(y'\gt0\) and rises to the stable one.

STRETCH · 10 marks Q5. Consider \(\dfrac{dy}{dx}=\dfrac{x^2+3y^2}{2xy}\) for \(x\gt0\). (a) Show that the substitution \(y=xu(x)\) makes it separable. (b) Solve the IVP with \(y(1)=1\).

Solution

(a) \(y'=u+xu'\); RHS \(=\dfrac{x^2+3x^2u^2}{2x^2u}=\dfrac{1+3u^2}{2u}\). So

$$xu'=\frac{1+3u^2}{2u}-u=\frac{1+u^2}{2u}\ \Longrightarrow\ \frac{du}{dx}=\frac1x\cdot\frac{1+u^2}{2u}\quad\text{— separable.}$$

(b) \(\displaystyle\int\frac{2u}{1+u^2}du=\int\frac{dx}{x}\Rightarrow\ln(1+u^2)=\ln x+C\Rightarrow1+u^2=Ax\). IC: \(u(1)=1\Rightarrow A=2\). So \(u^2=2x-1\), \(y^2=x^2u^2=2x^3-x^2\), and with \(y(1)=1\gt0\):

$$\boxed{y=\sqrt{2x^3-x^2}=x\sqrt{2x-1}},\quad x\gt\tfrac12.$$

8.3 · Linear first-order ODEs (integrating factor)

📖 Learn from these

Worked A — \(e^{t^2}\) integrating factor: \(y'+2ty=4t,\ y(0)=5\)

Q. Solve the IVP. [5 marks]

Already standard form, \(p=2t\). \(I=e^{\int2t\,dt}=e^{t^2}\).

$$\big(e^{t^2}y\big)'=4te^{t^2}\ \Longrightarrow\ e^{t^2}y=2e^{t^2}+C\ \Longrightarrow\ y=2+Ce^{-t^2}.$$

IC: \(5=2+C\Rightarrow\boxed{y=2+3e^{-t^2}}\).

This ODE is also separable (\(y'=2t(2-y)\)). Both methods give the same answer — use whichever you trust more under pressure.

Worked B — integration by parts inside: \(xy'-2y=x^4\sin x,\ y(\pi)=\pi^3\)

Q. Solve for \(x\gt0\). [8 marks]

Standard form (divide by \(x\gt0\)): \(y'-\dfrac2x\,y=x^3\sin x\). IF: \(I=e^{-2\ln x}=x^{-2}\).

$$\left(\frac{y}{x^2}\right)'=x\sin x\ \Longrightarrow\ \frac{y}{x^2}=\int x\sin x\,dx=-x\cos x+\sin x+C\quad(\text{by parts}).$$

IC: \(\dfrac{\pi^3}{\pi^2}=\pi=-\pi\cos\pi+\sin\pi+C=\pi+C\Rightarrow C=0\).

$$\boxed{y=x^2(\sin x-x\cos x)}$$

EXAM-LEVEL · 6 marks Q3. Solve \((x^2+1)y'+2xy=6x^2\), \(y(0)=4\).

Solution

Notice the LHS is exactly \(\dfrac{d}{dx}\big((x^2+1)y\big)\) (product rule). [Equivalently: standard form \(y'+\frac{2x}{x^2+1}y=\frac{6x^2}{x^2+1}\), \(I=x^2+1\).]

$$(x^2+1)y=\int6x^2\,dx=2x^3+C;\quad y(0)=4\Rightarrow C=4;\quad \boxed{y=\frac{2x^3+4}{x^2+1}}.$$

EXAM-LEVEL · 8 marks Q4. Solve \(xy'+3y=\dfrac{e^{x}}{x}\) for \(x\gt0\), with \(y(1)=2\).

Solution

Standard form: \(y'+\dfrac3x\,y=\dfrac{e^x}{x^2}\). \(I=e^{3\ln x}=x^3\) (\(x\gt0\)).

$$(x^3y)'=xe^x\ \Longrightarrow\ x^3y=(x-1)e^x+C\quad(\text{by parts}).$$

IC: \(2=0+C\Rightarrow C=2\): \(\boxed{y=\dfrac{(x-1)e^x+2}{x^3}}\).

STRETCH · 8 marks Q5. Find the general solution of \(y'+y\cot x=2\cos x\) on \(0\lt x\lt\pi\), and the solution with \(y\!\left(\frac\pi2\right)=3\). Justify how you simplify the integrating factor.

Solution

\(\int\cot x\,dx=\ln|\sin x|\), so \(I=|\sin x|=\sin x\) because \(\sin x\gt0\) on \((0,\pi)\).

$$(y\sin x)'=2\sin x\cos x=\sin 2x\ \Longrightarrow\ y\sin x=\sin^2x+C\ \Longrightarrow\ \boxed{y=\sin x+\frac{C}{\sin x}}.$$

(Using \(\int2\sin x\cos x\,dx=\sin^2x\); \(-\tfrac12\cos2x\) differs only by a constant.) IC: \(3=1+C\Rightarrow C=2\): \(\boxed{y=\sin x+2\csc x}\).

8.4 · Equilibrium solutions, stability & slope fields

📖 Learn from these

Worked A — autonomous quadratic: \(y'=(y-1)(y-4)\)

Q. Find and classify the equilibria. Describe the long-term behaviour for \(y(0)=2\) and \(y(0)=5\). [6 marks]

Equilibria \(y=1,\ y=4\). Signs: \(y\gt4\): \((+)(+)=+\); \(1\lt y\lt4\): \((+)(-)=-\); \(y\lt1\): \((-)(-)=+\).

  • \(y=1\): up from below, down from above ⇒ stable.
  • \(y=4\): away on both sides ⇒ unstable.

\(y(0)=2\): in \((1,4)\) with \(y'\lt0\), trapped above 1 ⇒ \(y\to1\). \(y(0)=5\): \(y'\gt0\) and increasing ⇒ \(y\) grows without bound (it actually blows up in finite time).

Worked B — non-autonomous (2020 S2 style): \(y'=(t-3)e^{y}(y-2)(y+1)^2\)

Q. Find all equilibrium solutions and decide which are stable. Justify. [10 marks]

Equilibria. Need \(y'=0\) for all \(t\): \(e^y\gt0\), \(t-3\) not identically 0, so \((y-2)(y+1)^2=0\): \(\boxed{y=2,\ y=-1}\).

Signs for \(t\gt3\). \(t-3\gt0\); \(e^y\gt0\); \((y+1)^2\gt0\) for \(y\ne-1\). So \(\operatorname{sign}(y')=\operatorname{sign}(y-2)\):

  • \(y\gt2\): \(y'\gt0\) (away from 2 upward).
  • \(-1\lt y\lt2\): \(y'\lt0\) (away from 2 downward, toward \(-1\)).
  • \(y\lt-1\): \(y'\lt0\) (away from \(-1\) downward).

Conclusion. \(y=2\) is unstable; \(y=-1\) is not stable (semi-stable). Neither is stable.

EXAM-LEVEL · 10 marks Q3. Find all equilibrium solutions of \(\dfrac{dy}{dt}=(1+t^2)(y^2-4)(y-1)^2\) and decide which are stable. Justify your answer. Hence find \(\lim_{t\to\infty}y(t)\) if \(y(0)=\tfrac32\).

\(1+t^2\gt0\) always, so equilibria are \(y=2,\ y=-2,\ y=1\). \((y-1)^2\gt0\) for \(y\ne1\), so \(\operatorname{sign}(y')=\operatorname{sign}\big((y-2)(y+2)\big)\):

  • \(y\gt2\): \(+\) · \(1\lt y\lt2\): \(-\) · \(-2\lt y\lt1\): \(-\) · \(y\lt-2\): \(+\).

\(y=2\) unstable; \(y=1\) semi-stable (not stable) — approached from above, left from below; \(y=-2\) stable.

\(y(0)=\tfrac32\): \(y'\lt0\) and \(y\) cannot cross \(y=1\) ⇒ \(y(t)\to1\).

EXAM-LEVEL · 8 marks Q4. (2020 S1 Q10 style.) Consider \(e^{t}\dot y+y^2=3y-2\). (a) Find all equilibrium solutions. (b) Determine whether each is stable. Justify.

Solution

(a) With \(\dot y=0\): \(y^2-3y+2=0\Rightarrow(y-1)(y-2)=0\Rightarrow y=1,\ y=2\).

(b) \(\dot y=e^{-t}(3y-2-y^2)=-e^{-t}(y-1)(y-2)\). Since \(e^{-t}\gt0\): \(y\gt2\): \(-\); \(1\lt y\lt2\): \(+\); \(y\lt1\): \(-\).

\(y=2\) stable (approached from both sides); \(y=1\) unstable.

STRETCH · 6 marks Q5. For \(y'=y-x\): (a) where are the slope-field segments horizontal? (b) Show \(y=x+1\) is a solution; is it an equilibrium? (c) Find the general solution and describe what solutions near the line \(y=x+1\) do as \(x\to\infty\).

Solution

(a) Horizontal where \(y-x=0\): along the line \(y=x\) (an isocline, not a solution).

(b) \(y'=1\) and \(y-x=1\) ✓. Not an equilibrium (not constant).

(c) Linear: \(y'-y=-x\), \(I=e^{-x}\), \((e^{-x}y)'=-xe^{-x}\Rightarrow e^{-x}y=(x+1)e^{-x}+C\Rightarrow\boxed{y=x+1+Ce^{x}}\). The gap from the line is \(Ce^x\), which grows: nearby solutions peel away (above if \(C\gt0\), below if \(C\lt0\)). The straight-line solution behaves like an unstable one.

Worked B — a big step jumps over an equilibrium: \(y'=4y(1-y),\ y(0)=\tfrac12\)

Q. Do two Euler steps with \(h=0.75\), then one step with \(h=0.5\). Comment. [5 marks]

\(h=0.75\): \(y_1=\frac12+\frac34\cdot4\cdot\frac12\cdot\frac12=\frac12+\frac34=\frac54\). \(y_2=\frac54+\frac34\cdot4\cdot\frac54\cdot\left(-\frac14\right)=\frac54-\frac{15}{16}=\frac5{16}\).

EXAM-LEVEL · 6 marks Q4. For \(y'=y^2\), \(y(0)=1\): (a) estimate \(y(0.5)\) by Euler with \(h=0.25\); (b) solve exactly and find the error; (c) what happens to the exact solution at \(x=1\)?

Worked A — falling with air resistance (Newton's 2nd law)

Q. A skydiver's velocity (downward positive, m/s) satisfies \(\dfrac{dv}{dt}=10-2v\) with \(v(0)=0\). (a) Solve for \(v(t)\). (b) Find the terminal velocity and explain it as an equilibrium. (c) When is \(v=4\)? (d) Find the distance fallen \(x(t)\) with \(x(0)=0\). [9 marks]

(a) Linear (or separable): \(I=e^{2t}\), \((e^{2t}v)'=10e^{2t}\Rightarrow e^{2t}v=5e^{2t}+C\), \(C=-5\): \(\boxed{v=5(1-e^{-2t})}\).

(b) \(v\to5\) m/s. \(v=5\) is the equilibrium of \(v'=10-2v\) (drag balances gravity); \(v'\gt0\) below and \(\lt0\) above ⇒ stable.

(c) \(4=5-5e^{-2t}\Rightarrow e^{-2t}=\frac15\Rightarrow t=\boxed{\tfrac12\ln5}\) s.

(d) \(x=\int_0^t5(1-e^{-2s})\,ds=\boxed{5t+\tfrac52\left(e^{-2t}-1\right)}\).

Worked B — growth with harvesting: \(P'=0.2P-40\)

Q. A fish population (\(t\) in years) obeys \(\dfrac{dP}{dt}=0.2P-40\). (a) Find and classify the equilibrium. (b) If \(P(0)=300\), when does \(P\) reach 500? (c) If \(P(0)=150\), when does the population die out? [8 marks]

(a) \(P'=\frac15(P-200)\): equilibrium \(P=200\), \(P'\gt0\) above and \(\lt0\) below ⇒ unstable (a "tipping point").

Solve: \(P-200=Ae^{t/5}\), so \(P=200+(P_0-200)e^{t/5}\).

(b) \(P=200+100e^{t/5}=500\Rightarrow e^{t/5}=3\Rightarrow t=\boxed{5\ln3}\) years.

(c) \(P=200-50e^{t/5}=0\Rightarrow e^{t/5}=4\Rightarrow t=\boxed{5\ln4=10\ln2}\) years.

STRETCH · 10 marks Q5. An object falls with quadratic air resistance: \(\dfrac{dv}{dt}=10-\dfrac{v^2}{10}\), \(v(0)=0\). (a) Find the terminal velocity from the ODE alone. (b) Solve for \(v(t)\). (c) When does the object reach half its terminal velocity?
