§1 · Concepts in depth

New to \(t_{n-1}\), \(\chi^2\), or quantile notation? Read the Ground Floor first — it builds the reference distributions and the \(1-\alpha/2\) quantile idea from scratch.

What a hypothesis test actually is

A hypothesis test is a decision procedure. You have data \(\mathbf{X}\) generated by some model with an unknown parameter \(\theta\) (e.g. a mean \(\mu\) or a proportion \(p\)). You must decide between two competing statements about \(\theta\):

  • Null hypothesis \(H_0\) — the "status quo", "no effect", "nothing interesting happening". This is the statement you assume true until the data forces you to abandon it.
  • Alternative hypothesis \(H_1\) — the statement you are trying to demonstrate (the effect, the difference, the improvement).

The two do not play equal roles. The notes' court-of-law analogy (notes §7.1): \(H_0\) = "innocent", \(H_1\) = "guilty". You only convict (reject \(H_0\)) if the evidence is strong "beyond reasonable doubt". If evidence is weak you fail to reject / accept \(H_0\) — this is NOT proof of innocence, just insufficient evidence to convict.

🧭 The core logic: proof by statistical contradiction

Before any formula, grasp the one idea the entire chapter is built on. A hypothesis test is a proof by contradiction, dressed in probability:

  1. Assume \(H_0\) is true. Pretend, for the sake of argument, that the null value (\(\mu=\mu_0\), \(p=p_0\), …) is exactly correct.
  2. Ask: how surprising would my data be, IF that were true? The test statistic pins down where the observed data sits in the distribution it would have under \(H_0\).
  3. If the data would be very unlikely under \(H_0\) — it lands far out in a tail — then \(H_0\) and the data are in conflict. We resolve the conflict by abandoning the assumption: we reject \(H_0\). The notes put it plainly (p 138): "reject \(H_0\) if the observed data … is very unlikely to have happened under \(H_0\)."
  4. If the data is perfectly ordinary under \(H_0\), there is no contradiction, so we keep the assumption (fail to reject).

The word statistical matters: unlike a logic-class contradiction (which disproves a claim with certainty), this one is measured on a probability scale — "the data would be too surprising to keep believing \(H_0\)". Everything below — test statistic, null distribution, P-value, \(\alpha\) — is just the machinery for answering the single question "how surprising is my data if \(H_0\) is true?". The 7-step ritual is the bookkeeping; this is the plot.

The engine: test statistic, null distribution, P-value

A test statistic \(T\) is a function of the data only, chosen so its value discriminates between \(H_0\) and \(H_1\). Under \(H_0\) it has a known distribution (the null distribution) — this is what lets us judge whether the observed \(t\) is "surprising".

The null distribution is just a sampling distribution: it is the spread of values \(T\) would take across all possible samples if \(H_0\) held. That is precisely the sampling-distribution / standard-error machinery from the Ground Floor — the null distribution is the reference ruler we lay the observed \(t\) against, and its shape (\(\mathcal N(0,1)\), \(t_{n-1}\), etc.) is fixed by \(H_0\) plus the model.

The P-value is the probability that, if \(H_0\) were true, the test statistic would be as extreme or more extreme than the value we actually observed (notes §7.1, formula sheet item 70). "More extreme" is defined by \(H_1\):

Alternative \(H_1\)Direction of extremeP-value
\(\mu \lt \mu_0\) (left one-sided)small \(t\) (area to left of \(t\), even if \(t\gt0\))\(\mathbb{P}_{H_0}(T\le t)\)
\(\mu \gt \mu_0\) (right one-sided)large \(t\) (area to right of \(t\), even if \(t\lt0\))\(\mathbb{P}_{H_0}(T\ge t)\)
\(\mu \ne \mu_0\) (two-sided)large \(|t|\) (both tails)\(2\,\mathbb{P}_{H_0}(T\ge |t|)\)

The P-value is the "surprise-o-meter". Small P-value = the data would be very unlikely under \(H_0\) = strong evidence against \(H_0\). It is NOT the probability that \(H_0\) is true.

What a P-value is NOT — three deadly misreadings. Read the definition's conditional direction carefully: \(P=\mathbb{P}(\text{data this extreme}\mid H_0\text{ true})\). It assumes \(H_0\) and asks about the data — never the reverse. So a P-value is:
  • NOT \(\mathbb{P}(H_0\text{ is true})\). \(P=0.03\) does not mean "3% chance \(H_0\) is true". \(H_0\) is either true or false; \(\mathbb{P}(H_0\text{ true})\) isn't even a quantity this framework can produce. Flipping the conditional is the single most common error.
  • NOT the probability your decision is wrong. The chance of a wrong rejection is \(\alpha\) — fixed in advance — not the P-value you happened to observe.
  • NOT \(\mathbb{P}(\text{results were due to chance})\) or \(\mathbb{P}(H_1\text{ true})\). And a large P-value is not evidence \(H_0\) is true — only a lack of evidence against it.
The only correct sentence: "IF \(H_0\) were true, data as extreme as ours (or more) would occur with probability \(P\)."

Strength of evidence & the decision rule

The smaller the P-value, the stronger the evidence against \(H_0\). The notes' rule of thumb (Figure 7.1):

P-valueEvidence against \(H_0\)
\(P \lt 0.01\)Strong
\(0.01 \le P \lt 0.05\)Moderate
\(0.05 \le P \lt 0.10\)Weak
\(P \ge 0.10\)Little / inconclusive

Decision rule: reject \(H_0\) if \(P \lt \alpha\), where \(\alpha\) is a pre-chosen significance level (usually 0.05). Choosing \(\alpha=0.05\) guarantees that the probability of wrongly rejecting a true \(H_0\) (a Type I error) is at most 0.05.

🧭 Why \(\alpha\) is chosen BEFORE looking at the data. The guarantee "false-rejection rate \(\le\alpha\)" only holds if \(\alpha\) is fixed in advance. If you first peeked at the data and then picked whatever threshold lets you reject, you could manufacture "significance" every time — the 5% promise would be worthless. Committing to \(\alpha\) up front is exactly what turns "the probability of a false rejection is at most \(\alpha\)" into an honest guarantee rather than a story fitted after the fact.

🧭 The duality: a two-sided test IS a confidence interval

A two-sided test at level \(\alpha\) and a \((1-\alpha)\) confidence interval are the same decision seen two ways:

  • Reject \(H_0:\theta=\theta_0\) at level \(\alpha\) \(\iff\) \(\theta_0\) falls outside the \((1-\alpha)\) CI for \(\theta\).
  • Fail to reject \(\iff\) \(\theta_0\) lies inside the CI.

Why they coincide: the \((1-\alpha)\) CI is defined as the set of null values \(\theta_0\) that the data would NOT reject. So the CI is literally "every hypothesis you cannot rule out at level \(\alpha\)". This is why Example 3 (2023 Q4) can conclude "0 is not in the interval \(\Rightarrow\) reject \(H_0\)" without a separate test — and why a CI is often the richer answer: it shows not just whether \(\theta_0\) is rejected, but the whole range of plausible values and by how much \(\theta_0\) misses.

The equivalence is exact only when the CI and the test use the same SE and same reference distribution (both \(t_{df}\), or both \(\mathcal N(0,1)\)), and it pairs a two-sided test with a two-sided interval. A one-sided test matches a one-sided (bound) interval. Note the proportion test breaks this: its test uses \(p_0\) in the SE while its CI uses \(\hat p\), so the two need not agree exactly.

"Statistically significant" ≠ large, important, or real-world meaningful. Significance says only that the effect is distinguishable from zero given the noise — it says nothing about the size of the effect. Because the statistic is (roughly) \(\text{effect}/SE\) and \(SE\) shrinks like \(1/\sqrt n\), a huge \(n\) makes even a trivially tiny effect "significant": with \(n\approx300\) per group the diet trial would flag a 0.1 kg difference as significant — statistically real, practically worthless. Conversely a large, important effect can be "non-significant" when \(n\) is tiny (low power). Always report the effect size / CI alongside the P-value, and never translate "significant" as "big" or "matters". (And "not significant" ≠ "no effect" — see the fail-to-reject trap in §6.)

The 7 steps of a statistical test (formula sheet item 69)

Every full-marks test answer walks these steps. Memorise the sequence — it is the skeleton for the flagship exam questions.

  1. Model — state the distributional assumptions for the data (e.g. \(X_1,\dots,X_n \overset{iid}{\sim} \mathcal N(\mu,\sigma^2)\)).
  2. Hypotheses — give \(H_0\) and \(H_1\) in mathematical form.
  3. Test statistic — write the statistic \(T\) and what it estimates.
  4. Null distribution — the distribution of \(T\) under \(H_0\) (incl. degrees of freedom).
  5. Outcome — plug in the numbers, get the observed \(t\).
  6. P-value — compute (or bracket from tables) using the \(H_1\) direction.
  7. Conclusion — accept/reject \(H_0\), then interpret in the context of the story.

In the exam the calculator is a Casio FX82 and you only get printed tables — so steps 4 and 6 mean "name the \(t_{df}\) or \(\mathcal N(0,1)\) distribution and bracket the P-value between two table entries". You are graded on the recipe, not on a decimal to 6 places.

🧭 Why every test statistic looks like (estimate − hypothesised) / SE

Look at the pattern across the whole chapter — one-sample \(t\), paired, two-sample, and the proportion \(Z\) all share one skeleton:

$$ T=\frac{\text{estimate} - \text{value claimed by } H_0}{\text{standard error of the estimate}}$$

Read it as a plain-English question: "how many standard errors does my estimate sit away from the value \(H_0\) claims?" The numerator is the raw gap between what we saw and what \(H_0\) asserts; dividing by the SE converts that gap into a unit-free ruler. A \(t\) or \(z\) of 3 always means "3 SEs from the claim", whether we are measuring pulse rates, weight change, or proportions. That is exactly why the same table of tail probabilities serves every test: once standardised, "3 SEs out" is equally surprising everywhere. Large \(|T|\) \(\Rightarrow\) the estimate is far from \(H_0\)'s claim in SE units \(\Rightarrow\) surprising under \(H_0\) \(\Rightarrow\) evidence against it. The notes reach this by insisting we "measure our deviation in units of \(\sigma\) rather than units of 1" (p 141); the SE itself is built from scratch in the Ground Floor.

Why a \(t\)-distribution and not Normal?

For a mean, the natural statistic is \(\bar X\). But we must "standardise" it by its spread. If \(\sigma\) were known we would use \(Z=(\bar X-\mu_0)/(\sigma/\sqrt n)\sim\mathcal N(0,1)\). In practice \(\sigma\) is unknown, so we plug in the sample SD \(S\). Replacing \(\sigma\) by the random estimator \(S\) adds extra variability, which fattens the tails: the result is a Student \(t_{n-1}\) distribution (notes §7.2, Theorem 6.7). The fewer the degrees of freedom, the fatter the tails. As \(df\to\infty\), \(t_{df}\to\mathcal N(0,1)\) (the last row of the \(t\)-table, item \(\infty\), IS the Normal quantiles).

For proportions we go the other way: there is no unknown nuisance \(\sigma\) (the variance \(p_0(1-p_0)\) is fixed by \(H_0\)), so the CLT gives a \(\mathcal N(0,1)\) statistic — no \(t\), no degrees of freedom.

§2 · Key tests & when to use them

All of these are on the provided formula sheet (items 69–76). The exam skill is recognition + execution, not recall. Learn the trigger for each.

1-sample \(t\)-test (sheet 72)

$$ T=\frac{\bar X-\mu_0}{S/\sqrt n}\ \overset{H_0}{\sim}\ t_{n-1}$$
You have ONE sample of measurements and a claimed/reference value \(\mu_0\). \(\sigma\) is unknown (the usual case). Model: \(X_1,\dots,X_n\overset{iid}{\sim}\mathcal N(\mu,\sigma^2)\); test \(H_0:\mu=\mu_0\).

\(H_1\) options: \(\mu\ne\mu_0\) (two-sided), \(\mu\gt\mu_0\), \(\mu\lt\mu_0\). Choose by the wording ("differs" vs "greater/exceeds" vs "less").

Paired \(t\)-test (1-sample \(t\) on the differences)

$$ D_i=X_i-Y_i,\qquad T=\frac{\bar D-\delta_0}{S_D/\sqrt n}\ \overset{H_0}{\sim}\ t_{n-1}$$
Two measurements on the SAME experimental units — "before & after", "left arm & right arm", "two labs on the same 15 patients". Collapse each pair to its difference \(D_i\) and run a one-sample \(t\)-test. Usually \(\delta_0=0\) (\(H_0:\mu_X-\mu_Y=0\)), but a claim like "3 mmHg larger" sets \(\delta_0=3\).

If the exam gives you a "difference" column with its own mean and SD (e.g. 2024 Q3), that is your signal it is paired: use \(n-1\) df where \(n\) = number of pairs, NOT \(m+n-2\).

2-sample \(t\)-test — Welch (unequal variances) (sheet 75)

$$ T=\frac{\bar X-\bar Y}{\sqrt{\dfrac{S_X^2}{m}+\dfrac{S_Y^2}{n}}}\ \overset{H_0}{\underset{\text{approx}}{\sim}}\ t_{df},\qquad df=\frac{\left(\dfrac{s_X^2}{m}+\dfrac{s_Y^2}{n}\right)^2}{\dfrac{s_X^4}{m^2(m-1)}+\dfrac{s_Y^4}{n^2(n-1)}}$$
Two independent groups (different subjects in each), and you are NOT willing to assume the two population variances are equal. This is R's t.test default. If using tables, round the Welch df DOWN to the nearest integer (notes p 150).

Conservative fallback if the df formula is too fiddly: \(df=\min(m-1,\,n-1)\) (sheet 75).

2-sample \(t\)-test — Pooled (equal variances) (sheet 74)

$$ S_p^2=\frac{(m-1)S_X^2+(n-1)S_Y^2}{m+n-2},\qquad T=\frac{\bar X-\bar Y}{S_p\sqrt{\dfrac1m+\dfrac1n}}\ \overset{H_0}{\sim}\ t_{m+n-2}\ \text{(exact)}$$
Two independent groups AND you assume equal population variances. Gives an exact \(t\) distribution with the clean \(m+n-2\) df. Use when sample SDs are close (rule of thumb below) or the question tells you to "assume equal variances / use the pooled SD".

Pooled vs Welch — how to decide (examiners love this)

The course uses this pragmatic rule: look at the ratio of the larger to the smaller sample SD.

SituationChooseJustification you write
SD ratio \(\lesssim 2\) (and/or symmetric histograms of similar spread)Pooled"The sample SDs are similar (ratio \(\approx\) …), so the equal-variance assumption is reasonable; I use the pooled test which gives an exact \(t_{m+n-2}\)."
SD ratio \(\gtrsim 2\), or clearly different spreads in the histogramsWelch"The sample SDs differ substantially (ratio \(\approx\) …), so I do not assume equal variances and use the Welch test."

Welch is always safe — if unsure, use Welch and say so. You lose no marks for defaulting to Welch, but you can lose marks for pooling when the spreads are obviously unequal.

1-sample proportion (binomial) test (sheet 73)

Exact (small \(n\)): test statistic \(X\sim\mathrm{Bin}(n,p_0)\) under \(H_0:p=p_0\); P-value from binomial tail probabilities.

$$ \text{Normal approx (large }n\text{): }\quad Z=\frac{\hat P-p_0}{\sqrt{p_0(1-p_0)/n}}\ \overset{H_0}{\underset{\text{approx}}{\sim}}\ \mathcal N(0,1),\quad \hat P=\tfrac Xn$$
Count / yes-no data vs a claimed proportion \(p_0\) ("is the coin fair, \(p_0=0.5\)?", "do more than 80% prefer…?"). Small \(n\): use the exact binomial. Large \(n\) (\(np_0\) and \(n(1-p_0)\ge5\)): the Normal approximation is acceptable.

The variance in the denominator uses \(p_0\) (the null value), NOT \(\hat p\). This differs from the CONFIDENCE-INTERVAL formula (sheet 67) which uses \(\hat p\). Test → \(p_0\); CI → \(\hat p\).

2-sample proportion test (sheet 76)

$$ \hat P=\frac{X+Y}{m+n}\ \text{(pooled)},\qquad Z=\frac{\hat P_X-\hat P_Y}{\sqrt{\hat P(1-\hat P)\left(\dfrac1m+\dfrac1n\right)}}\ \overset{H_0}{\underset{\text{approx}}{\sim}}\ \mathcal N(0,1)$$
Comparing two proportions from two independent groups ("are ABC viewers more left-wing than commercial viewers?", "are males more likely to be left-handed than females?"). Under \(H_0:p_X=p_Y\) the common \(p\) is estimated by the pooled proportion \(\hat P\) over BOTH groups.

Type I / Type II error & power

\(H_0\) is TRUE\(H_1\) is TRUE
Accept \(H_0\)✓ CorrectType II error (prob \(\beta\))
Reject \(H_0\)Type I error (prob \(\alpha\))✓ Correct — this is Power \(=1-\beta\)
  • Type I error = reject a true \(H_0\) (convict the innocent). Its probability is controlled at \(\le\alpha\) by the decision rule.
  • Type II error = fail to reject a false \(H_0\) (acquit the guilty). Its probability is \(\beta\).
  • Power \(=1-\beta=\) probability of correctly rejecting \(H_0\) when a specific \(H_1\) is true.

The two errors compete: shrinking \(\alpha\) inflates \(\beta\). Power rises with larger \(n\), larger true effect size \(|\mu-\mu_0|\), smaller \(\sigma\), and larger \(\alpha\). For a \(t\)-test the power depends on \(\mu\) and \(\sigma\) only through the ratio \(\mu/\sigma\) — the "signal-to-noise ratio" (notes §7.3).

Example 1 — One-sample \(t\)-test (notes Example, Decaf pulse data)

Q. Change in pulse rate for the Decaf (control) group: 4, 10, 7, −9, 5, 4, 5, 7, 6, 12 (\(n=10\)). Is there evidence the expected change is greater than 0?

1. Model: X₁,…,X₁₀ ~iid N(μ, σ²), σ unknown. 2. Hypotheses: H₀: μ = 0 vs H₁: μ > 0 (right one-sided — "greater than 0"). 3. Statistic: T = (X̄ − 0)/(S/√n), where X̄ = sample mean, S = sample SD. 4. Null dist: T ~ t₉. 5. Outcome: x̄ = 5.1, s = 5.587, t = 5.1 / (5.587/√10) = 2.89 (verified). 6. P-value (right tail): P(t₉ ≥ 2.89). t-table df=9: 2.82 → γ=0.99, 3.25 → γ=0.995. 2.82 < 2.89 < 3.25 ⇒ 0.005 < P < 0.01. (exact = 0.00899) 7. Conclusion: P < 0.01 ⇒ strong evidence; reject H₀. In context: the mean pulse-rate change for the decaf group is significantly greater than 0 — so a rise cannot be attributed to caffeine alone.

This shows the money skill: bracket the P-value from the \(t\)-table ("\(0.005\lt P\lt0.01\)") since you have no software.

Example 2 — Two-sample Welch AND pooled \(t\)-test (notes, Alice's caffeine data)

Q. Caffeinated group (\(m=10\)): mean 15.8, sd 8.32. Decaf (\(n=10\)): mean 5.1, sd 5.59. Does caffeine increase pulse rate?

1. Model: X₁,…,X₁₀ ~iid N(μ_X,σ_X²) [caff], Y₁,…,Y₁₀ ~iid N(μ_Y,σ_Y²) [decaf], independent. 2. Hypotheses: H₀: μ_X = μ_Y vs H₁: μ_X > μ_Y (i.e. μ_X − μ_Y > 0). ── WELCH (unequal variances) ── 3. T = (X̄ − Ȳ)/√(S_X²/m + S_Y²/n) 5. t = (15.8 − 5.1)/√(8.32²/10 + 5.59²/10) = 10.7/√(6.93+3.12) = 3.38 (verified 3.375) 4. df = (a+b)² / (a²/9 + b²/9) with a=S_X²/10, b=S_Y²/10 ⇒ df = 15.74 → round DOWN to 15. 6. P(t₁₅ ≥ 3.38): table df=15: 3.29 → 0.9975, 3.73 → 0.999 ⇒ 0.001 < P < 0.0025. (exact 0.00197) ── POOLED (equal variances) ── S_p² = (9·8.32² + 9·5.59²)/18 = 32.43 ⇒ S_p = 5.69 t = 10.7 / (5.69·√(1/10+1/10)) = 3.38, df = m+n−2 = 18 (EXACT t₁₈) P(t₁₈ ≥ 3.38): table df=18: 3.20→0.9975, 3.61→0.999 ⇒ 0.001 < P < 0.0025. (exact 0.00169) 7. Either way P < 0.01 ⇒ strong evidence; reject H₀. In context: caffeine significantly increases the change in pulse rate.

SD ratio \(8.32/5.59\approx1.5\;(\lt2)\) so pooling is defensible here; both routes give \(t=3.38\) and the same conclusion.

Example 3 — Paired \(t\)-test (notes Example 7.7/7.8, two labs, same 15 patients)

Q. Two labs measured the same 15 patients. Is there a difference between labs? lab1 and lab2 vectors given in notes.

Recognise PAIRED: same 15 patients measured by both labs ⇒ collapse to differences D = lab1 − lab2. 1. Model: D₁,…,D₁₅ ~iid N(μ_D, σ²). 2. Hypotheses: H₀: μ_D = 0 vs H₁: μ_D ≠ 0 (two-sided — "a difference"). 3. T = (D̄ − 0)/(S_D/√15) ~ t₁₄. 5. d̄ = −0.933, s_D = 2.052, t = −0.933/(2.052/√15) = −1.76 (verified). 6. P (two-sided) = 2·P(t₁₄ ≥ 1.76): table df=14: 1.76 → 0.95 ⇒ one tail ≈ 0.05, so P ≈ 0.10. (exact 0.0999) 7. P ≈ 0.10 ⇒ only weak/borderline evidence; do NOT reject H₀ at α=0.05. In context: no significant evidence the two labs give different results on average.

If you had wrongly treated these as two independent samples of 15 you would use \(t_{28}\) and get the wrong SE — the pairing removes patient-to-patient variability and is far more powerful.

Example 4 — One-sample proportion test (notes Example 7.4–7.6, yoghurt)

Q. 8 of 10 people preferred the new sweetener. Evidence that the new style is preferred (\(p\gt0.5\))?

1. Model: X = # preferring new ~ Bin(10, p). 2. Hypotheses: H₀: p = 0.5 vs H₁: p > 0.5. 3. Statistic: X (exact test). 4. Under H₀: X ~ Bin(10, 0.5). 5. Outcome: x = 8. 6. EXACT P-value = P(X ≥ 8) = Σ_{k=8}^{10} C(10,k)(0.5)^10 = 0.0547 (verified). NORMAL APPROX: p̂ = 0.8, z = (0.8−0.5)/√(0.5·0.5/10) = 1.897, P = P(Z ≥ 1.90) = 1 − Φ(1.90) = 1 − 0.9713 = 0.0287. 7. Exact P = 0.055 (weak evidence — borderline, do not reject at 0.05). The two P-values differ a lot (0.055 vs 0.029) because n=10 is too small for the Normal approximation ⇒ for small n prefer the EXACT binomial test.
Example 5 — Two-sample proportion test (notes Example 7.9/7.10, ABC viewers)

Q. 40/70 ABC viewers vs 50/100 commercial viewers claim left-wing allegiance. Are ABC viewers more left-wing?

1. Model: X ~ Bin(70, p_X) [ABC], Y ~ Bin(100, p_Y) [commercial], independent. 2. Hypotheses: H₀: p_X = p_Y vs H₁: p_X > p_Y. 3&4. Z = (p̂_X − p̂_Y)/√(p̂(1−p̂)(1/m+1/n)) ~ N(0,1), with pooled p̂ = (X+Y)/(m+n). 5. p̂_X = 40/70 = 0.571, p̂_Y = 0.50, p̂ = 90/170 = 0.529. z = (0.571−0.500)/√(0.529·0.471·(1/70+1/100)) = 0.918 (verified). 6. P = P(Z ≥ 0.92) = 1 − Φ(0.92) = 1 − 0.8212 = 0.179. 7. P = 0.18 ⇒ little evidence; do NOT reject H₀. In context: no evidence that ABC viewers are more left-wing than commercial viewers.
Example 6 — Power of a test (notes Example 7.3)

Q. One-sample \(t\)-test, \(H_0:\mu=0\) vs \(H_1:\mu\gt0\), \(\alpha=0.05\), \(n=5\). What is the power when the truth is \(\mu=1,\sigma=2\)?

Signal-to-noise: μ/σ = 0.5. Reject if t = X̄/(S/√5) exceeds t₄,0.95 = 2.13. Under the alternative T has a NON-CENTRAL t₄ with ncp = μ/(σ/√n) = 1/(2/√5) = 1.118. Power = P(reject | H₁) = 0.239 (verified; notes report 0.24). Same calc with n = 50 ⇒ power = 0.967.

Takeaway you can be asked to explain: with a small effect (\(\mu/\sigma=0.5\)) and \(n=5\) the test almost never detects the effect (power 24%); raising \(n\) to 50 pushes power to 97%. More data ⇒ more power.

§4 · Exam question types (mined from past papers)

Hypothesis testing appears in every paper, usually as a 15–20 mark multi-part question and often the single most valuable question on the paper. Below are the styles that actually appear.

Type A — Two-sample \(t\)-test from a summary table flagship · ~19 marks

Looks like: a table of \(n\), means and SDs for two groups; you must state hypotheses, run the test, and justify pooled vs Welch from histograms/SDs. This is the highest-value question on the paper.

Recipe:
  1. CI part first if asked (one-sample \(t\) CI on one group).
  2. State \(H_0:\mu_X=\mu_Y\) vs \(H_1\) (direction from wording) — define every symbol.
  3. Choose pooled vs Welch (SD ratio + histogram shape). State which.
  4. Compute \(t\) to 2 sig figs; state df.
  5. Bracket the P-value from the \(t\)-table.
  6. Statistical conclusion + one sentence in context.
  7. State & check assumptions (independence, normality) from the plots.

Real example — 2025 Q3 (Gardner diet trial), the flagship. Low-Carb: \(n=304\), mean weight change \(-5.99\) (SD 5.69). Low-Fat: \(n=305\), \(-5.29\) (SD 5.70). "Did one diet produce a different change than the other?"

Full worked solution — 2025 Q3(a)–(d)
(a) 95% CI for LC mean weight change (one-sample t, df=303): t₀.₉₇₅,₃₀₃ ≈ 1.97 (t-table ∞/df=200 row ≈ 1.97) −5.99 ± 1.97·(5.69/√304) = −5.99 ± 0.64 = (−6.63, −5.35) kg (verified) Interpret: we are 95% confident the true mean weight change on LC is between −6.63 and −5.35 kg — an average LOSS (interval entirely below 0). (b) Notation & hypotheses [explain all notation!]: Let μ_LC = population mean 12-month weight change on the low-carb diet, μ_LF = population mean 12-month weight change on the low-fat diet. H₀: μ_LC = μ_LF vs H₁: μ_LC ≠ μ_LF (two-sided — "a DIFFERENT change"). (c) Two independent groups on the CHANGE scores. Perform two-sample t-test. diff = −5.99 − (−5.29) = −0.70 SE (Welch) = √(5.69²/304 + 5.70²/305) = 0.4615 t = −0.70 / 0.4615 = −1.5 (to 2 sig figs) (verified −1.52) df: Welch ≈ 607 (huge) → use ∞ row of t-table. [Pooled: t₆₀₇, identical to 2 sf.] P (two-sided) = 2·P(Z ≥ 1.52): table ∞: 1.28→0.90, 1.64→0.95 ⇒ one tail between 0.05 and 0.10 ⇒ 0.10 < P < 0.20. (exact 0.13) Conclusion: P ≈ 0.13 > 0.05 ⇒ do NOT reject H₀. In context: no significant evidence that the two diets produce different average weight change at 12 months. (d) Assumptions: (i) observations independent within & between groups (randomised trial ⇒ satisfied). (ii) Approximate normality of each group's change scores — histograms of "12-month change" are roughly symmetric & bell-shaped, and n is large (CLT), so satisfied. Pooled vs Welch: sample SDs are 5.69 and 5.70 — essentially IDENTICAL (ratio ≈ 1.002 ≪ 2), so the equal-variance assumption is very reasonable. Pooled is justified here; Welch gives the same answer to 2 sf.

Type B — Paired \(t\)-test (same subjects, two measurements) ~9–13 marks

Looks like: a table with a "difference" column (its own mean and SD), or wording "measured at baseline and again after…" on the SAME subjects. Signals paired.

Recipe: work on the differences \(D=X-Y\). \(H_0:\mu_D=\delta_0\) (usually 0). \(t=(\bar d-\delta_0)/(s_D/\sqrt n)\sim t_{n-1}\). Bracket P, conclude in context.

Real example — 2024 Q3 (forearm vs upper-arm blood pressure, 44 subjects). Difference column: mean 2.22, SD 9.64, \(n=44\).

Full worked solution — 2024 Q3(a)–(e)
(a) Let μ_D = mean of (Forearm − Upper-arm) systolic BP differences, per person. H₀: μ_D = 0 vs H₁: μ_D ≠ 0 (two-sided — is the forearm a valid alternative site?). (b) PAIRED (same subjects, forearm & upper arm) ⇒ one-sample t on differences. t = 2.22/(9.64/√44) = 2.22/1.453 = 1.5 (2 sig figs) (verified 1.53) df = 43. P (two-sided) = 2·P(t₄₃ ≥ 1.53): table df=40: 1.30→0.90, 1.68→0.95 ⇒ one tail 0.05–0.10 ⇒ 0.10 < P < 0.20. (exact 0.134) Conclusion: P ≈ 0.13 > 0.05 ⇒ do NOT reject H₀. No significant difference between forearm & upper-arm measurements ⇒ forearm is a plausible alternative site. (c) Claim: forearm 3 mmHg LARGER ⇒ H₀: μ_D = 3 vs H₁: μ_D ≠ 3. t = (2.22 − 3)/(9.64/√44) = −0.78/1.453 = −0.54, df=43. (verified) P (two-sided) huge (>0.5) ⇒ no evidence against the 3 mmHg claim. (d) 95% CI for σ of the differences (chi-squared, df=43): q₁ = χ²₄₃,₀.₀₂₅ ≈ 26.8, q₂ = χ²₄₃,₀.₉₇₅ ≈ 63.0 ( 43·9.64²/63.0 , 43·9.64²/26.8 ) → σ ∈ (7.96, 12.21) mmHg. (verified) Assumption: the differences are normally distributed. (e) Sample size so 95% margin of error ≤ 1 mmHg, using s_D = 9.64: 1.96·9.64/√n ≤ 1 ⇒ n ≥ (1.96·9.64)² = 357.0 ⇒ n = 357. (verified)

Type C — Two-sample test + CI from small samples (pooled) ~18 marks

Looks like: two small independent groups with near-equal SDs; asks for a CI on the mean difference and a one-sided test of a claim.

Real example — 2023 Q4 (sheep vs goat pâté protein). Sheep: \(n=6\), mean 20.7, SD 0.17. Goat: \(n=6\), mean 19.2, SD 0.17. Normally distributed.

Full worked solution — 2023 Q4(a)–(c)
(a) Let μ_s, μ_g = population mean protein (g / 100g) of sheep & goat pâté. Researcher's question ("is there a difference"): H₀: μ_s = μ_g vs H₁: μ_s ≠ μ_g. (b) SDs identical (0.17 = 0.17) ⇒ POOLED, exact t₁₀. S_p = 0.17 (pooled of two equal SDs). diff = 20.7 − 19.2 = 1.5. SE = 0.17·√(1/6+1/6) = 0.0981. t₀.₉₇₅,₁₀ = 2.228 ⇒ 95% CI = 1.5 ± 2.228·0.0981 = 1.5 ± 0.219 = (1.281, 1.719) g. (verified) Statistical conclusion: 0 is NOT in the interval ⇒ reject H₀ at 5%. In context: sheep pâté has significantly higher mean protein than goat pâté. (c) Producer claims sheep have "at least 2g more" ⇒ test H₀: μ_s − μ_g = 2 vs H₁: μ_s − μ_g < 2. t = (1.5 − 2)/0.0981 = −5.09, df=10. (verified −5.094) P(t₁₀ ≤ −5.09): |t|=5.09 > 4.59 (=t₁₀,₀.₉₉₉₅) ⇒ P < 0.0005. Type D — Proportion tests & Type-I/II/power exercises notes / tutorial level

Looks like: count data vs a target (one-sample), two count groups (two-sample), or a "find \(\alpha\), \(\beta\), power" exercise with an explicit rejection region. See notes §7.7 Exercises 5, 6, 9 and Examples 7.4–7.10 (all worked in §3 above).

Type-I/II drill (notes Ex 6): reject \(H_0:p=0.8\) if \(X\le12\), \(X\sim\mathrm{Bin}(20,p)\).

§6 · Traps & marks lost

Paired vs independent. The most common lost marks. "Same subjects measured twice" (before/after, two sites, two labs on same patients) is paired — use \(t_{n-1}\) on differences, NOT \(t_{m+n-2}\). A given "difference column" is a dead giveaway.
\(H_0\) must contain the equality. \(H_0\) always has "\(=\)" (or \(\le/\ge\) with equality on the boundary). Never write \(H_0:\mu\gt\mu_0\). The strict inequality goes in \(H_1\).
One-sided vs two-sided. "Different / changed" ⇒ two-sided (double the tail). "Greater/less/more/exceeds" ⇒ one-sided. Getting this wrong halves or doubles your P-value and can flip the conclusion. Read the question's verb.
Proportion test uses \(p_0\), the CI uses \(\hat p\). In the test statistic the denominator is \(\sqrt{p_0(1-p_0)/n}\) (null value). The confidence interval uses \(\sqrt{\hat p(1-\hat p)/n}\). Mixing them up is a classic error.
Welch df must be rounded DOWN for tables. The notes say so explicitly (p 150). A Welch df of 15.74 becomes \(t_{15}\), not \(t_{16}\). Then bracket from the table.
Don't over-round intermediate steps. Keep full precision (e.g. SE) and round only the FINAL statistic to the requested sig figs. Rounding \(S_p\) early then squaring can shift the last digit.
Small-\(n\) proportion: use the EXACT binomial. With \(n=10\) the Normal approximation (P = 0.029) is badly off from the exact (P = 0.055) — different conclusions at \(\alpha=0.05\)! The Normal approx needs \(np_0\ge5\) and \(n(1-p_0)\ge5\).
"Do not reject \(H_0\)" ≠ "\(H_0\) is true". A large P-value means insufficient evidence, not proof of no effect. Write "no significant evidence of a difference", never "the means are equal".
Always finish with the context sentence. "Reject \(H_0\)" alone typically loses the final mark. The examiner wants "there is significant evidence that [the caffeine increases pulse rate / the diets differ / …]".
Bracket the P-value; don't fabricate a decimal. You have only the FX82 and printed tables — you cannot compute \(\mathbb{P}(t_{43}\ge1.53)=0.134\) exactly. Quote "\(0.10\lt P\lt0.20\)". That earns full marks; a made-up "\(P=0.13\)" without justification does not.
State assumptions even when not explicitly asked in a "perform a test" part. Independence + normality (via histograms/QQ or CLT for large \(n\)) are worth marks in the flagship questions. Tie each to the provided figure.

§7 · Self-check

1. A study measures each patient's cholesterol before and after a drug and asks "did cholesterol change?" Which test, what df, one- or two-sided?

Paired \(t\)-test (same patients, before & after) = one-sample \(t\) on the differences. df \(=n-1\) where \(n=\)#patients. "Change" (not "decrease") ⇒ two-sided.

2. Two independent groups, \(m=n=6\), sample SDs 0.17 and 0.17. Pooled or Welch, and what df?

SDs identical (ratio 1.0 ≪ 2) ⇒ pooled, exact \(t_{m+n-2}=t_{10}\). (This is 2023 Q4.)

3. You compute \(t=2.89\) on \(t_9\) for a right-sided test. Bracket the P-value from the \(t\)-table.

df=9 row: \(2.82\to0.99\), \(3.25\to0.995\). Since \(2.82\lt2.89\lt3.25\), one-tail \(P\) is between 0.005 and 0.01: \(\boxed{0.005\lt P\lt0.01}\). Strong evidence, reject \(H_0\).

4. Same \(t=2.89\), \(t_9\), but now a TWO-sided test. P-value?

Double the tail bracket: \(2\times(0.005,0.01)=\boxed{0.01\lt P\lt0.02}\). Still reject at 0.05.

5. 8 of 10 people prefer product A; test \(H_0:p=0.5\) vs \(H_1:p\gt0.5\). Why prefer the exact binomial over the Normal \(Z\)?

\(n=10\) is small; \(np_0=5\) is only just at the threshold. Exact P \(=\mathbb{P}(X\ge8)=0.055\) vs Normal-approx \(0.029\) — they straddle 0.05 and give different decisions. For small \(n\) the exact binomial is correct.

6. Write, with full notation, the hypotheses for "does low-carb produce a different mean weight change than low-fat?" (2025 Q3b)

Let \(\mu_{LC},\mu_{LF}\) be the population mean 12-month weight changes on the low-carb and low-fat diets. \(H_0:\mu_{LC}=\mu_{LF}\) vs \(H_1:\mu_{LC}\ne\mu_{LF}\) (two-sided — "different").

7. In the diet trial you fail to reject \(H_0\). What is a Type II error in context, and how would you increase power?

Type II error = concluding the diets produce the same weight change when in truth they differ. Increase power by: larger sample sizes, a larger true effect, smaller variability, or a larger \(\alpha\).

8. Two-sample proportion test: 20/153 males vs 16/154 females are left-handed. What is the pooled \(\hat P\) and the null distribution of \(Z\)?

\(\hat P=(20+16)/(153+154)=36/307=0.117\). Under \(H_0:p_M=p_F\), \(Z=\dfrac{\hat p_M-\hat p_F}{\sqrt{\hat P(1-\hat P)(1/153+1/154)}}\overset{\text{approx}}{\sim}\mathcal N(0,1)\). (Tutorial 6 / notes Ex 7.9-style.)

STRETCH · 3 marks Q4. In Q3 you rejected \(H_0\) with \(0.0025\lt P\lt0.005\). A teammate writes "so there is a \(99.7\%\) chance the true mean beats 120 s." Explain in one sentence why that reading is wrong, and give the correct interpretation of the P-value.

📖 Learn from these

Worked A — same typists, two keyboards (recognise the pairing)

Q. Ten office workers each type a standard passage on a membrane keyboard and again on a mechanical keyboard (order randomised). For each typist the change \(D=\text{(mechanical} - \text{membrane)}\) in words-per-minute is recorded; the differences have mean \(\bar d = 4.3\) WPM and SD \(s_D = 5.2\) WPM. Is there a difference between keyboards?

Recognise PAIRED: the SAME 10 typists use both keyboards ⇒ one measurement per pair ⇒ collapse to differences D and run a one-sample t-test on D (NOT t₁₈). 1. Model: D₁,…,D₁₀ ~iid N(μ_D, σ²). 2. Hypotheses: Let μ_D = mean of (mechanical − membrane) WPM per typist. H₀: μ_D = 0 vs H₁: μ_D ≠ 0 (two-sided — "a difference"). 3. Statistic: T = (D̄ − 0)/(S_D/√10). 4. Null dist: T ~ t₉ (n = 10 pairs ⇒ df = 9). 5. Outcome: t = 4.3/(5.2/√10) = 4.3/1.6444 = 2.61 (verified 2.615). 6. P (two-sided) = 2·P(t₉ ≥ 2.61): df=9 2.262 → .975 (tail .025), 2.821 → .99 (tail .01) ⇒ one tail (0.01,0.025) ⇒ 0.02 < P < 0.05. (exact 0.028) 7. P < 0.05 ⇒ reject H₀. In context: evidence the two keyboards give different mean typing speeds (mechanical faster in this sample).

Worked A — one-sample proportion, Normal approx (seed germination)

Q. A seed supplier claims a \(92\%\) germination rate. A gardener sows \(n=80\) seeds and \(68\) germinate. Is there evidence the true rate is below \(0.92\)? \(\alpha=0.05\).

Statistic (Normal approx, denominator uses p₀): Z = (p̂ − p₀)/√(p₀(1−p₀)/n), p̂ = 68/80 = 0.85. Check: n·p₀ = 73.6 ≥ 5, n(1−p₀) = 6.4 ≥ 5 ⇒ Normal approx acceptable. 4. P < 0.05 ⇒ reject H₀. In context: evidence the true germination rate is below the claimed 92%. [Exact binomial P(X ≤ 68 | p=0.92) = 0.025 — same decision; use exact if asked.]

8.5 · Non-zero & one-sided "claim" nulls ("at least \(k\) more…")

When a claim is "at least \(k\) more/larger/longer", put the boundary value \(k\) in \(H_0\) and test the direction that would disprove the claim: \(H_0:\theta=k\) vs \(H_1:\theta\lt k\). The statistic becomes \(t=(\text{estimate}-k)/SE\) — the hypothesised value \(k\), not \(0\), goes in the numerator.

8.6 · Type I / II error & power in context

📖 Learn from these

Worked A — quality-control decision rule (Type I, Type II, power)

Q. A machine should produce acceptable parts with probability \(p=0.9\). From a batch, \(n=20\) parts are inspected and the line is stopped (reject \(H_0:p=0.9\)) if the number acceptable is \(X\le 16\). (a) Find \(\alpha=\mathbb P(\text{Type I})\). (b) If the machine has degraded to \(p=0.75\), find \(\beta\) and the power.

X ~ Bin(20, p). Rejection region: X ≤ 16. (a) Type I error = stop the line when it is actually fine (p = 0.9): α = P(X ≤ 16 | p = 0.9) = 0.133. (verified 0.13295) (b) Under the alternative p = 0.75: β = P(fail to stop | p = 0.75) = P(X > 16 | p = 0.75) = P(X ≥ 17 | p = 0.75) = 0.225. (verified 0.22516) Power = 1 − β = P(X ≤ 16 | p = 0.75) = 0.775. Context: when the machine is fine there is a 13% chance of a needless stop (Type I); when it has degraded to 75% acceptable, the rule correctly stops the line 77.5% of the time (power) but misses the fault 22.5% of the time (Type II).

To shrink \(\alpha\) you would tighten the rule (e.g. stop only if \(X\le15\)) — but that raises \(\beta\). The two errors trade off; only more data (larger \(n\)) improves both at once.

Worked B — power of a one-sample \(t\)-test (signal-to-noise)

Q. A one-sample \(t\)-test of \(H_0:\mu=0\) vs \(H_1:\mu\gt0\) at \(\alpha=0.05\) uses \(n=8\). What is the (approximate) power if the truth is \(\mu=2,\ \sigma=3\)? What happens at \(n=30\)?

Reject if T = X̄/(S/√8) > t₇,.₉₅ = 1.895. Signal-to-noise: μ/σ = 2/3 = 0.667. Non-centrality ncp = μ/(σ/√n) = 2/(3/√8) = 1.886. Under H₁, T ~ non-central t₇ with ncp = 1.886. Power = P(T > 1.895 | H₁) = 0.52 (verified 0.522). With n = 30: ncp = 2/(3/√30) = 3.65 ⇒ power = 0.97 (verified 0.972).

Same effect \(\mu/\sigma\), very different power: \(n=8\) is a coin-flip (52%), \(n=30\) is near-certain (97%). Power rises with \(n\), with a larger true effect \(|\mu|\), with smaller \(\sigma\), and with larger \(\alpha\).

WARM-UP · 3 marks Q2. In the bakery test of §8.5 Q1 you rejected the "\(\ge800\) g" claim. Describe, in the story's language, what a Type I and a Type II error would be here, and one way to raise the power.

Solution
Type I error: concluding the loaves average under 800 g when in truth they average at least 800 g (falsely accusing the bakery of underweight loaves). Type II error: failing to detect underweight loaves when they truly average below 800 g (letting a genuinely underweight product pass). Raise power by: weighing more loaves (larger n), or if the true shortfall is larger / the weight variability (σ) smaller — all push power up.

STRETCH · 3 marks Q3. Two labs run the same one-sample \(t\)-test on the same true effect. Lab A uses \(\alpha=0.05\); Lab B uses \(\alpha=0.01\). Which has higher power, and what have they traded to get it?

Solution
Lab A (α = 0.05) has the LARGER rejection region, so higher power (smaller β) — it detects the effect more often. The trade-off: a larger α means a higher Type I error rate (more false rejections when H₀ is actually true). Lowering α to 0.01 (Lab B) guards harder against false positives but sacrifices power. You cannot shrink both α and β at fixed n; only more data improves both.
