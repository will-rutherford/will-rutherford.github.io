What you're walking into

Two scenario questions, each worth 25 marks, each written in its own 6-page booklet. Every question ends with something like "Advise Emma… Please use ILAC to answer this question." That last sentence usually tells you the area of law ("under Tort Law", "under the Australian Consumer Law", "applying Contract Law 3 only", "under the law of agency").

It's open book, so you don't need to memorise anything. You do need to (1) recognise which topic a question is, (2) know the ILAC shape, and (3) find the right pre-written paragraphs fast. This pack is built for exactly that:

  • Every topic page has a Learn it section, a Spot it table, an ILAC script (the sentences to write, in order, with blanks to fill), full model answers to real past questions, and a printable sheet.
  • Print binder = all the sheets in one document. Answer binder = every model answer in one document. Print both (about 28 + 60 pages), tab them by topic, and take them in. The full answer binder (~150 pages, including the extra answer banks) is for reading on screen tonight.

Exam routine (the 130 minutes)

  1. Planning (10 min): read both questions. For each one, read the last paragraph first ("Advise X… under ___"). That names the area. Flip to that tab. Circle every fact that triggers an element (warnings, alcohol, signed contract, "assured", elderly or poor English, "free range" label…). Jot the list of issues and the order you'll do them in on the booklet's first page.
  2. Q1 (55 min) → Q2 (55 min) → 10 min buffer. Do your stronger topic first. Don't go over time on one question: a half-finished second answer loses far more marks than a slightly shorter first one.
  3. For each issue, write in this order: Issue (one sentence with a "?"), Law (copy the topic's Law paragraph, cutting what doesn't apply), Application (go element by element using the script's starters, the parties' names and the actual facts, and say "Similar to [case]…" at least once), Conclusion ("On the balance of probabilities…").
  4. Finish with Remedies (and Defences if the topic has them). Use the actual dollar figures from the question.
  5. If a fact is missing, write "There is insufficient information as to ___; assuming ___, …". The exam instructions explicitly allow this.
