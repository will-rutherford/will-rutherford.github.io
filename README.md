# will-rutherford.github.io

UQ exam study packs, published via GitHub Pages. The root page is a subject picker.

| Folder | Subject | Exam |
|---|---|---|
| `stat1301/` | STAT1301 — Advanced Analysis of Scientific Data | November 2026 |
| `math1052/` | MATH1052 — Multivariate Calculus & Ordinary Differential Equations | end of Semester 2, 2026 |

Each pack has the same anatomy: a command hub (`index.html`), chapter pages (concepts → key methods →
worked examples → exam question types → wording triggers → traps → self-check → Practice Arena),
`foundations.html`, `formulas.html`, `notebook.html`, and fully worked past papers (`exam-YYYY.html`).
Every page's nav starts with **⇄ Switch subject**, which returns to the picker. See each folder's README.
